📖 Правила

Цель

  • Расставьте плитки по порядку — 1, 2, 3… слева направо и сверху вниз; пустая клетка — в правом нижнем углу. В режиме «Картинка» — соберите рисунок.
  • Каждая раскладка гарантированно решаема (проверяется чётность перестановки с учётом ряда пустой клетки) и хорошо перемешана.

Ход

  • Тап по плитке в одном ряду или столбце с пустой клеткой сдвигает к ней сразу все плитки между ними — как пальцем на настоящих пятнашках.
  • Свайп по полю сдвигает в сторону свайпа плитку, соседнюю с пустой клеткой. Стрелки / WASD — то же с клавиатуры.
  • Ходы считаются по плиткам: сдвиг трёх плиток одним тапом — 3 хода.
  • Плитка на своём месте загорается цветом своего ряда (на картинке с номерами — зелёный номер).

Поля и режимы

  • 3×3 (8 плиток) — разминка, 4×4 — классические пятнашки, 5×5 и 6×6 — для терпеливых.
  • 🔢 Числа — классика. 🖼 Картинка — неоновый рисунок, нарезанный на плитки; номера-подсказки в углу включаются кнопкой #, а 👁 Образец (удерживайте) показывает целый рисунок.
  • 📅 Пятнашки дня — одна раскладка 4×4 в день, одинаковая у всех. Засчитывается первая сборка дня, серия 🔥 растёт, если собирать каждый день.

Помощь

  • 💡 Подсказка (H) — следующий ход из текущей позиции: на 3×3 — по кратчайшему решению, на 4×4 — по кратчайшему, если решатель успеет его найти (иначе по близкому к нему), на 5×5 и 6×6 — по решению «ряд за рядом». Идите по подсказкам — дойдёте до сборки.
  • Партия с подсказкой засчитывается в статистику с пометкой 💡, но без рекорда.
  • 🤖 Решение — компьютер собирает головоломку у вас на глазах (остановить можно в любой момент). Такая партия не засчитывается.

Рекорды

  • Время идёт с первого хода, на паузе стоит, а поле скрыто.
  • Рекорды — отдельно для каждого поля и режима: наименьшее число ходов и лучшее время (это могут быть разные партии).
  • Незаконченная партия сохраняется сама — для каждого поля и режима своя.

Управление

  • Стрелки / WASD — ход, H — подсказка, V (удерживать) — образец, N — номера на картинке, P / Esc — пауза, R — новая раскладка.
  • Быстрые ходы подряд не теряются — анимация догоняет.
