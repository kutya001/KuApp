📖 Правила

Цель

  • Открыть все пары одинаковых карточек за наименьшее число попыток.

Как играть

  • Тап по карточке открывает её. Затем открой вторую.
  • Картинки совпали — пара остаётся открытой. Нет — обе карточки закроются через секунду: запомни, где что лежит.
  • Попытка — каждые две открытые карточки. Точность = пары ÷ попытки (100% — без единой ошибки).

Рекорды

  • Для каждого поля сохраняются лучшие попытки и лучшее время.
  • Время идёт с первой открытой карточки и стоит на паузе. P / Esc — пауза.
