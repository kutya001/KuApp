## 1. Обзор проекта

**KuApp** — мобильная прогрессивная веб-платформа (PWA), объединяющая фитнес-инструменты, языковое обучение и коллекцию мини-игр. Центральный хаб (`index.html`) управляет навигацией, авторизацией, статистикой и данными. Все приложения загружаются внутри `<iframe>` и взаимодействуют с платформой через единый `PlatformAPI`.

Всё работает **без сервера** — чистый HTML/CSS/JS, данные хранятся в Google Sheets, хостинг на GitHub Pages.

| Модуль | Кол-во | Описание |
|---|---|---|
| 🏋️ Фитнес | 2 | Таймер тренировок + конструктор программ |
| 📖 Обучение | 1 | Словарь с карточками, тестами, рейтингом |
| 🎮 Игры | 18 | Аркады, головоломки, логика |

### Навигация и вкладки

Платформа имеет 5 основных вкладок. На десктопе отображаются в боковой панели, на мобильных — в нижней навигации.

| Вкладка | Иконка | Описание |
|---|---|---|
| **Приложения** | 📱 | Сетка всех приложений с поиском. Показывает время последнего запуска. |
| **Статистика** | 📊 | Какой пользователь, какое приложение запускал, сколько раз, сколько времени провёл. Фильтры по приложению и пользователю. |
| **Рейтинг** | 🏆 | Рейтинг пользователей по суммарному времени в приложениях. Раскрываемая детализация по приложениям. |
| **Справочники** | 📚 | Полный CRUD-доступ ко всем листам Google Sheets. Сгруппированы по префиксу (sys_, dict_). Создание/удаление листов, строк, редактирование ячеек. |
| **Настройки** | ⚙️ | 4 подвкладки: Общие (аккаунт, БД, юзеры), Кэш (CRUD по localStorage), Обновление (SW, кэши), Разработчику (промт-инструкция). |

### PlatformAPI

Приложения обращаются к платформе через `window.parent.PlatformAPI`:

```javascript
const Platform = window.parent?.PlatformAPI;

// Пользователь
Platform.user.getProfile()   // → { username, role, totalXP }
Platform.user.isAdmin()      // → true/false
Platform.user.getRole()      // → "admin" | "user"

// База данных
Platform.db.read(range)
Platform.db.append(range, values)
Platform.db.update(range, values)
Platform.db.batchValues(data)
Platform.db.batchStructural(requests)
Platform.db.ensureTables([{ name, headers }])
Platform.db.getSpreadsheetId()

// Очки
Platform.gameplay.submitScore(appId, rawScore, xpEarned)

// Логирование (сессии трекаются автоматически платформой)
Platform.system.logSession(appId, durationSec)
Platform.system.log(appId, eventType, details)

// UI
Platform.ui.showToast(msg, type)   // type: 'ok' | 'err' | ''
Platform.ui.showLoader(on)
Platform.ui.openSettings()
```

### Сетевая игра (KuNet)

Пошаговые игры можно играть вдвоём по сети через тот же GAS-бэкенд: **Крестики-нолики, Реверси, Wall Rush, Бильярд, Судоку (дуэль)**.
Комнаты живут в `CacheService` (до 6 часов), таблица не используется. Клиент, чей ход, отправляет новое состояние
целиком с ожидаемой версией; сервер проверяет токен игрока, очередь хода и версию. Второй клиент опрашивает
комнату раз в 2 с (4 с, когда ходит сам). Задержка хода — около 1–3 с, поэтому игры реального времени
(Пинг-понг) остаются локальными.

Клиентская библиотека: `apps/kunet.js`. Подключение в игре:

```html
<script src="kunet.js"></script>
<script>
KuNet.openLobby({
  game: 'tictac', title: 'КРЕСТИКИ-НОЛИКИ · ПО СЕТИ',
  initialState: () => ({ board: Array(9).fill(null), current: 'X' }),
  onStart: (sess) => {           // комната укомплектована
    sess.seat;                   // 0 — создатель (ходит первым), 1 — гость
    sess.onUpdate = room => applyState(room.state);
    sess.onClosed = () => showOpponentLeft();
    sess.startPolling();
  }
});
// мой ход:            sess.move(state, nextSeat, moveInfo, finished)
// новая партия:       sess.reset(initialState, 0[, round])   (идемпотентно по раунду: если соперник уже начал
//                     новый раунд, сервер вернёт его, а не начнёт ещё один; может нажать любой)
// initialState может вернуть Promise (например, игра готовит головоломку) — кнопка «Создать комнату» ждёт его
// выход:              sess.leave()
</script>
```

Действия GAS (`gas/Code.gs`): `roomCreate`, `roomJoin`, `roomGet`, `roomMove`, `roomReset`, `roomLeave`, `roomList`.
Код комнаты — 4 символа; открытые комнаты видны в лобби игры 30 минут.

### База данных (Google Sheets)

Платформа хранит данные в Google Sheets через Google Apps Script (прокси).

**Системные таблицы (создаются платформой):**

| Лист | Столбцы | Назначение |
|---|---|---|
| `sys_Users` | ID, Email (логин), Password (хэш), Role, TotalXP, CreatedAt, Status | Аккаунты пользователей |
| `sys_Logs` | Timestamp, Email, AppID, EventType, Details | Журнал сессий и событий приложений |
| `sys_Scores` | Timestamp, Email, AppID, RawScore, XP | Очки и результаты игр |

> Приложениям системные листы недоступны: `Platform.db.*` отклоняет диапазоны с префиксом `sys_`, а сервер
> требует роль `admin` для любой записи в них (кроме журнала). Все значения записываются как текст
> (`setNumberFormat('@')`, а строки, начинающиеся с `=`, экранируются ведущим апострофом), поэтому
> `=IMPORTXML(...)` не исполняется, а `"0123"` не превращается в `123`.

**Таблицы Словаря (создаются приложением):**

| Лист | Столбцы | Назначение |
|---|---|---|
| `dict_languages` | code, name | Языки |
| `dict_categories` | id, name, icon | Категории слов |
| `dict_words` | category, lang_from, word_from, lang_to, word_to, transcription | Словарный запас |
| `dict_ratings` | login, words_learned, quizzes_done, quiz_score, last_active | Рейтинг |

> Любое приложение может создавать свои листы через `Platform.db.ensureTables()`. Рекомендуемый формат: `appname_tablename` (только `[a-zA-Z0-9_]`).

### Система пользователей

**Вход по коду доступа.** Логинов и паролей нет: пользователь вводит код, сервер (`gas/Code.gs`, действие `loginCode`)
определяет по нему роль и выдаёт персональный ID и токен сессии.

Коды хранятся в **Script Properties** проекта Apps Script (Настройки проекта → Свойства скрипта):

| Свойство | По умолчанию | Роль |
|---|---|---|
| `ADMIN_CODE` | `123321` | `admin` — полный доступ: таблицы, пользователи, журнал |
| `PLAYER_CODE` | `112233` | `player` — игры по сети, общий рейтинг, XP |

Если свойств нет, они создаются с этими значениями при первом входе. Чтобы сменить код, отредактируйте
свойство — новый код действует сразу, уже выданные сессии живут до 6 часов.
URL веб-приложения вшит в `index.html` (`HARDCODED_GAS_URL`); вся проверка кодов выполняется на сервере.

- **Гость** (без кода) играет во все игры локально; сетевые комнаты, рейтинг и настройки недоступны.
- **Персональный ID** вида `P-XXXXXX` выдаётся при первом входе, хранится в `localStorage` (`kuapp_pid`)
  и присылается при следующих входах, поэтому XP и имя сохраняются за устройством. Роль при каждом входе
  берётся из кода: один и тот же ID может войти как игрок или как администратор.
- **Имя** (необязательно) показывается в сетевых играх и рейтинге вместо ID.
- **Журнал.** Каждый вход пишется в `sys_Logs`: `login` (с ролью и именем), `login_failed` (неверный код),
  `login_blocked` (ID заблокирован администратором).
- **Сессия.** После входа клиент получает `{ login, playerId, name, role, total_xp, token }`. Токен живёт
  в `CacheService` 6 часов (продлевается при каждом запросе), хранится в `localStorage` (`mcg_user`) и уходит
  в каждый запрос к GAS. Просроченный токен → `{ ok:false, code:"AUTH_EXPIRED" }`, платформа переводит
  пользователя в режим Гостя. `logout` отзывает токен.
- **Права проверяет сервер.** Роль берётся из `sys_Users` в момент запроса — правка localStorage ничего не даёт.
- Приложения получают профиль через `Platform.user.getProfile()` (`playerId`, `name`, `role`, `isGuest`)
  и токен через `Platform.user.getToken()` (нужен `kunet.js` для сетевых комнат).

| Кто | Что доступно |
|---|---|
| Гость (без токена) | `meta`; чтение любых листов, кроме `sys_Users`; запись в листы приложений (не `sys_*`); `append` в `sys_Logs`; `roomGet` / `roomList` |
| Игрок (`player`) | + `roomCreate` / `roomJoin` (игры по сети); `addXP` — очки и XP пишет сервер в `sys_Scores` / `sys_Users` по ID из токена; `me` |
| Администратор (`admin`) | + любая запись в `sys_*`; чтение `sys_Users`; `addSheets` / `deleteSheet` / `deleteRows`; блокировка и смена роли через **Настройки → Общие → Управление пользователями** |

`sys_Users`: `ID, Email (= ID), Password (не используется), Role, TotalXP, CreatedAt, Status, Name`.

## 3. Первоначальная настройка

> Подробная инструкция по настройке Google Sheets и Google Apps Script — в [Технической спецификации](Artifacts/TECH_SPEC.md#9-инфраструктура-и-развёртывание).

### 1. Создайте Google Таблицу

Откройте [Google Sheets](https://sheets.google.com) и создайте новую таблицу. ID таблицы — часть URL:
```
https://docs.google.com/spreadsheets/d/ВОТ_ЭТОТ_ID/edit
```

### 2. Разверните Google Apps Script

1. В таблице откройте **Расширения → Apps Script**
2. Вставьте код из [`gas/Code.gs`](gas/Code.gs)
3. Сохраните проект
4. Нажмите **Начать развертывание → Веб-приложение**
   - Выполнять как: **От моего имени**
   - У кого есть доступ: **Все**
5. Скопируйте URL развёртывания

### 3. Откройте доступ к таблице

В таблице нажмите **«Поделиться»** и добавьте email сервисного аккаунта (если используется) с ролью **«Редактор»**.

### 4. Настройте платформу

1. Откройте приложение (первый запуск покажет экран настройки)
2. Введите **URL Google Apps Script**
3. Нажмите **«Сохранить»** — платформа проверит подключение и создаст системные листы
4. Зарегистрируйте первый аккаунт — он станет администратором

### 🟦 Тетрис

| | |
|---|---|
| **Файл** | `apps/tetris.html` |
| **Категория** | 🎯 Другое |
| **Описание** | Неоновый тетрис по современным правилам (Tetris Guideline): 6 режимов + Block Blast, темы, рекорды, достижения — эталон единого стиля игр |

- **Режимы:**
  - **🏁 Марафон** — 150 линий и победа; начальный уровень 1–15, уровень растёт каждые 10 линий (не выше 15-го).
    Вариант **♾️ Без конца** — тот же марафон без финиша (прежний «Классический», его рекорд сохранён).
  - **🏃 Спринт** — 40 линий на время (время останавливается в момент очистки 40-й линии), скорость 1-го уровня.
  - **⏱️ Ультра** — больше всего очков за 2 минуты.
  - **⛏️ Копатель** — внизу 10 линий мусора с одной дыркой (дырка не над дыркой), расчистить на время.
  - **🧘 Дзен** — без проигрыша: скорость не растёт, при переполнении нижние ряды убираются сами (стопка опускается
    до середины), спокойный темп музыки; сессию завершает игрок («🏁 Завершить сессию» в паузе).
  - **🧩 Block Blast** — фигуры перетаскиваются на поле 8×8, очищаются ряды и столбцы.
- **Правила (Guideline):** поле 10×20 + 20 строк буфера; SRS с таблицами сдвигов (отдельная для I), O не вращается;
  фигуры появляются в строках 21–22 в столбцах 4–6 (I и O — по центру), плоской стороной вниз, и сразу опускаются на
  строку, если свободно; мешок 7; удержание — раз на фигуру; 5 следующих; задержка фиксации 0,5 с, сдвиг/поворот на
  опоре продлевает её не больше 15 раз (после 15-го фигура на опоре фиксируется сразу, счёт обнуляется, когда фигура
  опускается ниже); скорость падения — `(0,8 − (ур − 1)·0,007)^(ур − 1)` с на строку (с 20-го уровня — 20G);
  мягкий сброс не фиксирует. Проигрыш — **block out** (новой фигуре негде появиться) или **lock out** (фигура
  зафиксировалась целиком выше поля); частично выше поля — игра идёт (клетки в буфере отмечены красным у края).
  T-Spin — правило 3 углов (последний ход — поворот); Mini — если заняты не оба угла со стороны выступа, кроме поворота
  с 5-й проверкой (TST-сдвиг) — тот всегда полный. Поворот на 180° (таблица SRS+) — по желанию, в настройках.
- **Очки** (× уровень до очистки): 1/2/3/4 линии — 100/300/500/800; T-Spin без линий/1/2/3 — 400/800/1200/1600;
  Mini T-Spin без линий/1/2 — 100/200/400; Back-to-Back (тетрис или T-Spin с линиями подряд) ×1,5; комбо —
  50 × комбо × уровень; Perfect Clear +800/1200/1800/2000 (B2B-тетрисом — +3200); мягкий сброс 1, жёсткий 2 за клетку.
  T-Spin без линий серию B2B не прерывает, фигура без линий обнуляет комбо.
- **Управление:** ← → движение (свой автоповтор DAS/ARR), ↓ мягкий сброс, пробел — жёсткий, ↑/X ↻, Z/Ctrl ↺,
  A — 180° (если включён), C/Shift — удержание, P/Esc — пауза. Телефон: тап — ↻, тап двумя пальцами — ↺ (или 180°),
  свайп в стороны — движение, вниз — спуск, рывком — сброс, вверх — удержание, тап по HOLD — удержание.
  **Экранные кнопки** (по желанию): ← ↓ → и жёсткий сброс слева, ↺ ↻ HOLD и 180° справа; в портрете — под полем,
  в альбоме — по краям экрана; удержание ← → ↓ работает с автоповтором, несколько пальцев одновременно.
- **Настройки:** DAS 50–333 мс (по умолчанию 167), ARR 0–100 мс (33), мягкий сброс ×5/×10/×20/×40/мгновенно (×20),
  поворот 180°, экранные кнопки, 5 тем, размер поля (6–12 × 12–24) и масштаб, ghost, звук, музыка «Коробейники»,
  вибрация; экспорт/импорт JSON, сброс рекордов, полный сброс (только ключи Тетриса).
- **Рекорды и статистика:** по режимам — очки (марафон, без конца, ультра, дзен, Block Blast) и лучшее время (спринт,
  копатель); история 100 последних партий с уровнем старта и размером поля; 22 достижения (новые: «Тройной финт» —
  T-Spin Triple, «Марафонец», «Шахтёр», «Нирвана»); в окне итогов — причина проигрыша и открытые за партию достижения.
- **Движок** — чистая функция `TE` без DOM (шаг 1 мс — одинаково на 60/120/144 Гц); тесты в Node берут его прямо из
  `tetris.html`: сверка таблиц SRS с TetrisWiki и тысячи случайных поворотов против эталона, T-Spin Triple/Double/Mini,
  очки, задержка фиксации, мешок 7, DAS/ARR, режимы.
- **Платформа:** очки в `PlatformAPI` Тетрис не отправляет (как и раньше).
- **Хранилище** (`localStorage`): `t_settings` (+ `startLevel`, `marathon`, `das`, `arr`, `sdf`, `rot180`, `pad`),
  `t_best` (+ `marathon`, `dig`, `zen`), `t_history`, `t_ach`, `t_stats` (+ `marathonWins`, `digWins`, `bestDig`,
  `zenLines`); `t_best_classic`, `t_best_blast` — перенос рекордов первой версии. Данные прежней версии читаются как
  есть, испорченные значения заменяются значениями по умолчанию.

  повороте экрана меняется только размер клетки. Все лабиринты проверены: связны, без тупиков, из старта достижима
  каждая свободная клетка (S/M/L, портрет и альбом).
- **Игра:** фиксированный шаг логики (одинаковая скорость на 60/120/144 Гц), плавное движение головы и хвоста
  (настройка), отсчёт 3-2-1 перед стартом и после паузы, пауза при скрытии вкладки.
- **Управление:** свайп в любом месте экрана (можно вести палец и поворачивать снова), экранная крестовина
  (настройка; в альбоме — справа от поля, поле ничем не перекрыто), клавиши стрелки / WASD / 8-4-6-2, P / Esc — пауза.

### 🏓 Пинг-понг

| | |
|---|---|
| **Файл** | `apps/pong.html` |
| **Категория** | 🕹️ Аркады |
| **Описание** | Неоновый пинг-понг по правилам настольного тенниса: матч с ИИ 4 уровней и 8 характеров, турнир из 7 соперников, кампания из 10 уровней с преградами, выживание и игра вдвоём на одном экране |

Отбивайте мяч ракеткой и забивайте за спину соперника. Счёт и подача — как в настольном теннисе, мяч летит
по-аркадному: угол — от места удара, закрутка — от движения ракетки, скорость растёт в розыгрыше.

- **Режимы:** **Матч с ИИ** — соперник Новичок / Любитель / Профи / Мастер и характер (Ровный, Стена, Атака, Винт),
  партия до 5 / 11 / 21, «разница в 2» по выбору, матч из 1 партии или до 2 / 3 побед; **Турнир** — лестница из
  7 соперников (Айбек «Новичок», Нургуль «Торопыга», Тимур «Стена», Айгерим «Винт», Эрлан «Ураган», Жылдыз «Снайпер»,
  Бакыт «Мастер»; финал — до 2 побед), прогресс сохраняется, поражение — переиграть того же соперника, победа над всеми —
  титул чемпиона; **Кампания** — 10 уровней (преграды, кирпичи, бонусы «шире» и «мультимяч»), до 3–5 очков раньше ИИ,
  открытые уровни можно переигрывать; **Выживание** — до первого пропущенного мяча, с каждым голом ИИ сильнее и подача
  быстрее; **Вдвоём** — на одном устройстве, формат партии как в матче.
- **Правила счёта и подачи:** подача переходит каждые 2 очка (в партии до 21 — каждые 5), при «больше-меньше» (10:10,
  4:4, 20:20 с разницей в 2) — каждое очко; первого подающего определяет жребий, в следующей партии первым подаёт
  первым принимавший; мяч лежит на ракетке подающего (тап, щелчок, пробел или сам через 3 с); подача с края поля идёт
  по диагонали к центру. В шапке — «ГЕЙМБОЛ», «МАТЧБОЛ», «БОЛЬШЕ-МЕНЬШЕ», под полем — «Ваша подача (1 из 2)».
- **Физика:** фиксированный шаг 1/120 с (одинаково на 30–144 Гц и неровных кадрах); вдоль поля мяч всегда летит со
  «скоростью розыгрыша» (33 км/ч на подаче, +4,5 % за удар, предел 80 км/ч), угол удара (до 42° у края ракетки) и
  закрутка меняют только боковую скорость — удар краем быстрее; закрутка от движения ракетки: мяч уходит в сторону
  движения и дугой загибается обратно, закрученный мяч чуть «соскальзывает» с ракетки соперника; угол полёта ≤ 50°,
  после удара ≥ 3° — вечных боковых и прямых траекторий нет; подшаги ≤ R/2 и непрерывная проверка лицевой линии
  ракетки — мяч не проходит сквозь ракетку на любой скорости; поле ведёт себя одинаково стоя и лёжа.
- **ИИ:** замечает удар с задержкой (0,38 → 0,2 с от Новичка к Мастеру), прогнозирует траекторию с ошибкой (растёт
  после бортов, на скорости, с закруткой — у тех, кто её не читает), уточняет прогноз по мере подлёта, ракетка
  разгоняется и тормозит; устаёт в длинном розыгрыше; «не успевает» за далёкими быстрыми мячами и изредка грубо
  ошибается на скорости. Характеры отличаются надёжностью, углами (Атака, Снайпер — подальше от вас), закруткой (Винт),
  риском ударов краем и возвратом в центр. Процент отбитых случайных мячей: 53 / 78 / 89 / 94 % по уровням.
- **Управление:** телефон — ведите пальцем в любом месте экрана (в том числе под полем), быстрый тап — подача;
  компьютер — мышь, W S / ↑ ↓ (поле лёжа) или A D / ← → (поле стоя), пробел / Enter / щелчок — подача, P / Esc — пауза.
  Вдвоём: каждый — своей половиной экрана (стоя — низ и верх, лёжа — лево и право; мультитач, палец, заехавший за
  середину, ведёт свою ракетку), клавиши игрока 1 — W S (A D), игрока 2 — ↑ ↓ (← →). Поле — стоя на телефоне и лёжа в
  альбомной ориентации и на компьютере (в настройках можно закрепить). Пауза при скрытии вкладки.
- **Статистика, достижения, история:** матчи, победы, серии, очки и партии против ИИ, эйсы, лучший розыгрыш, самый
  быстрый отбитый мяч, победы и поражения по уровням ИИ, турнир, кампания, выживание, время в игре; 15 достижений
  («Эйс», «Марафон», «Больше-меньше», «Камбэк», «Всухую», «Мастер повержен», «Чемпион» и др.); 40 последних матчей.
- **Настройки:** звук, вибрация, тряска экрана, чувствительность 50–200 % (палец/мышь — усиление от центра поля,
  клавиши — скорость ракетки), поле авто / стоя / лёжа, партия по умолчанию (до 5/11/21, матч, разница в 2), сброс
  статистики и прогресса (настройки сохраняются).
- **Проверка:** стресс-тест физики (60 000 мячей до 3000 ед/с, в том числе против ракетки, движущейся со скоростью
  до 2600 ед/с, — ни одного прохода сквозь ракетку; угол, скорость, «ловушки» среди преград, частота кадров),
  правила подачи и счёта против независимого «судьи» (60 000 матчей всех 18 форматов + живые матчи ИИ), поведение ИИ
  (уровни, усталость, закрутка, характеры), сценарии в браузере (касания одним и двумя пальцами, мышь, клавиши, все
  режимы и окна, телефон стоя/лёжа, 360×640, компьютер, испорченные данные хранилища).
- **Платформа:** очки в `PlatformAPI` Пинг-понг не отправляет (как и раньше).
- **Хранилище** (`localStorage`): `pong_stats` (поля прежней версии `played`, `wins`, `campaign`, `endless`, `freeW`,
  `freeL` сохранены — старые рекорды и прогресс кампании видны сразу), `pong_settings`, `pong_history`, `pong_ach`,
  `pong_tour`. Испорченные значения заменяются значениями по умолчанию.

### 🧱 Арканоид

| | |
|---|---|
| **Файл** | `apps/breakout.html` |
| **Категория** | 🕹️ Аркады |
| **Описание** | Полноценный Арканоид: 32 уровня-узора, 4 босса, 7 классических капсул, кампания со звёздами, «Аркада» и бесконечный режим |

Отбивайте мяч ракеткой и разбейте все кирпичи, кроме золотых. Упали все мячи — минус жизнь. Угол отскока зависит от
места удара о ракетку, мяч со временем разгоняется. Уровни свои (оригинальные узоры), механика — как в классике.

- **Режимы:** **Кампания** — 32 уровня по порядку, на каждый 3 жизни, звёзды, выбор открытых уровней;
  **Аркада** — как в автомате: все 32 уровня подряд на 3 жизни, очки копятся, доп. жизнь за 20 000 и далее каждые 60 000;
  **Бесконечный** — генератор симметричных узоров без конца, 5 жизней, сложность и скорость растут, каждый 8-й этап — босс.
- **Уровни** (4 мира по 8): Первый контакт · Ущелье · Сердце · Ракета · Шахматы · Пришелец · Пирамида · **Страж** |
  Тундук · Ала-Тоо · Бомбы · Крепость · Волна · Соты · Мишень · **Кристалл** | Ключ · Фантомы · Лабиринт · Корона · Юрта ·
  Песочные часы · Цепная реакция · **Улей** | Спираль · Калпак · Беркут · Решётка · Звезда · Бастион · Буря · **Ядро**.
  Сложность растёт плавно: скорость мяча (старт 300 → 455 ед/с, предел 500 → 700), прочность серебра, золото,
  взрывные, «живые» кирпичи, враги. Следующий уровень открывается после прохождения; в окне выбора — мини-превью узоров.
- **Кирпичи:** цветные (белый 50 … жёлтый 120 очков), серебряные (2 удара на уровнях 1–8, +1 каждые 8 уровней, до 5;
  50 × номер уровня очков), золотые (не бьются), взрывные (разносят 8 соседей, кроме золота, цепочкой),
  «живые» (через 9 с восстанавливаются, для прохождения не нужны, очки — только за первый раз).
- **Капсулы** (как в классике; капсула +1000): S — замедление, C — ловля (мяч прилипает, запуск тапом или сам через 2,5 с),
  E — ракетка в 1,5 раза шире, D — мяч делится на три, L — лазер (стреляет сам), B — ворота в правой стене: увести в них
  ракетку — уровень пройден, +10 000; P — +1 жизнь. На поле одна капсула, при нескольких мячах капсулы не падают, одна и
  та же не выпадает дважды подряд; действует один эффект — новая капсула отменяет прежнюю (кроме P). Шанс — 16 % с кирпича,
  B и P редкие.
- **Боссы** (каждый 8-й уровень): Страж, Кристалл, Улей, Ядро — шкала прочности 12/16/20/26 ударов, движутся по своим
  траекториям, стреляют (прицельно, веером, очередями, «дождём» с предупреждением), с половины прочности — злее.
  Снаряд в ракетку — минус жизнь. Каждые 4 удара босс роняет капсулу; лазер наносит 0,2 урона.
- **Враги:** вылетают из ворот сверху, плывут вниз, обходя кирпичи; мяч от них отскакивает, они сбиваются (+100).
  Число врагов за уровень ограничено.
- **Физика:** фиксированный шаг 1/240 с (одинаково на 30/60/120/144 Гц); непрерывные столкновения (мяч доводится до
  точки касания и отражается, сквозь кирпич не проскакивает ни на какой скорости); грани между соседними кирпичами
  «внутренние» (ряд — ровная стена без ложных углов); удар краем ракетки — до 60° от вертикали, мяч никогда не летит
  положе 25° к горизонтали; после 10 отскоков без толку (стены, золото) угол чуть сбивается — вечных петель нет.
- **Очки:** кирпичи с комбо (разбитые подряд без паузы > 2 с: ×2 с 3-го … ×5), капсула +1000, враг +100, удар по
  боссу +500, босс повержен 5 000–20 000, проход B +10 000, в конце уровня 500 за каждую оставшуюся жизнь.
  На платформу (`submitScore('breakout', …)`, XP = очки / 200): в кампании — только прирост лучшего результата уровня,
  в «Аркаде» и «Бесконечном» — только прирост рекорда по окончании забега. Повтор не «фармится».
- **Звёзды:** ★ — уровень пройден, ★★ — потеряна одна жизнь, ★★★ — без потерь.
- **Управление:** мышь — ракетка за курсором, клик — запуск/выстрел; ← → (A D) — ракетка, пробел / ↑ — запуск,
  P / Esc — пауза. Телефон: ведите пальцем в любом месте экрана (в том числе под полем) — ракетка повторяет движение,
  палец не закрывает мяч; тап — запуск. Альбомная ориентация: поле во всю высоту, показатели слева, пауза справа.
  Пауза при скрытии вкладки.
- **Настройки:** звук, вибрация, тряска и вспышки, чувствительность (50–250 %), режим пальца «Тянуть» / «Под пальцем»,
  сброс прогресса. **Статистика** по режимам и всего (кирпичи, капсулы по видам, враги, боссы, время…),
  **16 достижений**.
- **Проверка:** стресс-тест физики (≈100 000 отскоков на скоростях до 3000 ед/с — ни одного прохода сквозь кирпич,
  стену или ракетку, угол ≥ 25°), правила капсул и кирпичей, бот проходит все 32 уровня и 48 этапов бесконечного
  (плюс проверка достижимости кирпичей), бои с боссами с уклонением, сценарии в браузере (мышь, клавиатура, касания).
- **Хранилище** (`localStorage`): `breakout_progress` (звёзды, лучшие очки и время по уровням), `breakout_endless_best`
  (рекорд бесконечного — прежний ключ), `breakout_records` (рекорд «Аркады», дальние уровень и этап),
  `breakout_stats`, `breakout_ach`, `breakout_settings`. Прогресс прежней версии (`breakout_completed`, `breakout_best`,
  16 секторов) переносится при первом запуске: сектор N → уровень N с теми же звёздами.

  (≈5 и ≈3 клетки), мяч упруго отскакивает. Супер-прыжок: 15 с прыжков ×1,55 (≈6,5 клетки), таймер в HUD, кристалл

- **Физика** — фиксированный шаг 1/240 с (одинаково на 60 и 120 Гц), круг против рёбер клеток со скруглёнными
  углами, склоны на полу и потолке (с длинного склона мяч разгоняется), вода с выталкиванием по доле погружения.

Беги, перепрыгивай кактусы и уворачивайся от птеродактилей. Механика — как у Chrome Dino (мир 600 ед. в ширину,

масштабируется: время на реакцию одинаковое на телефоне и компьютере.

- **Механика** (фиксированный шаг 1/60 с — одинаково на 30/60/120/144 Гц; между тиками положения интерполируются):
  скорость растёт на 0,001 ед/тик за тик от стартовой до максимальной (Классика: 6 → 13, на экране ×1.0 → ×2.2,
  за ~2 мин); очки = пройденное расстояние × 0,025. Прыжок: старт 10 + скорость/10, тяжесть 0,6; короткий тап —
  ≈ 62 ед., удержание ≥ 0,13 с — полный ≈ 91 ед. (отпустил раньше — подъём обрезается, но не ниже минимума; тап
  короче кадра тоже даёт прыжок). ↓ в воздухе — быстрое падение (×3), держишь ↓ при приземлении — сразу присед;
  из приседа прыгнуть нельзя; прыжок, нажатый за ≤ 0,1 с до приземления, не теряется.
- **Препятствия:** малые и большие кактусы по 1–3 — группа только когда скорость позволяет её перепрыгнуть (малые
  со скорости 4, большие с 7); птеродактили с ×1.4 (≈ 450 очков) на трёх высотах: низкий — перепрыгнуть,
  средний — пригнуться, под высоким — пробежать (прыгать нельзя); птица летит на 0,8 быстрее или медленнее земли.
  Зазор = ширина × скорость + 72…90, разброс до ×1,5 — растёт со скоростью; не больше двух одинаковых подряд;
  первые 3 с — без препятствий.

  и хитбоксы в движке; хитбоксы лежат внутри нарисованного во всех кадрах анимации и закрывают 70–78 % площади.
- **Ночь, темы, эпохи:** каждые 700 очков — ночь на 12 с (луна с фазами, звёзды, неон ярче); посреди ночи меняется

  новая эпоха I–IV. Стартовая тема — в настройках. Препятствия контрастнее фона ≥ 3:1 во всех темах, эпохах,
  на любой стадии ночи и посреди перехода тем.
- **Режимы:** 🦖 **Классика**; 📅 **Испытание дня** — правила Классики, трасса задана датой и одинакова у всех;

  60/120/144 Гц и без «проскоков» на любой скорости. Дужка — две окружности (передний и задний край кольца) плюс
  крепление к щиту; щит — отскок с потерей энергии (e = 0,65) и трением; сетка — «вязкие» стенки и торможение внутри,
  мяч проходит сквозь; пол — отскок и качение. Удар — импульс с трением и вращением мяча (обратное вращение «гасит»
  мяч на дужке и стекле), сопротивление воздуха считается относительно ветра (ветер задан в м/с). Движущиеся кольцо
  и препятствия передают мячу свою скорость.
- **Засчитывание:** центр мяча пересёк плоскость кольца сверху вниз между дужками. Прошёл кольцо снизу вверх — бросок
  уже не засчитать; коснулся пола — промах; застрял на дужке или между дужкой и щитом — промах. **Чистый** — без
  касания дужки и щита (сетку задевать можно), **от щита** — попадание после касания щита.
- **🏀 Кампания — 30 уровней** (1–16 — прежние номера, звёзды игроков сохраняются; названия 1–15 прежние, бывший
  «ФИНАЛ» 16 стал «Рубежом», финал теперь 30-й): Разминка · Пониже ·
  Движение · Ветерок · Барьер · Ветер + Движ · Вверх-вниз · Коридор · Динамика · Сложный ветер · Стена · Хаос ·
  Двойной барьер · Шторм · Лабиринт · Рубеж · Только чистые · От щита · Вслепую · Из-за дуги · Серия · Карусель ·
  Низкий потолок · Защитник · Блиц · Порывы · Орбита · Снайпер · Буря · ФИНАЛ. Кольцо ездит по горизонтали, вертикали
  и по кругу; ветер 1,5–6 м/с в обе стороны, на части уровней — порывами (меняется перед каждым броском); стенки,
  планки, «потолок» и «защитник» (неподвижные и движущиеся); цели «забей N из M», «только чистые», «только от щита»,
  «N подряд», «5 за 30 секунд»; точки броска по кругу; уровни без подсказки и с короткой. Звёзды — за промахи
  (в «Блице» — за оставшееся время), правило звёзд показано в начале уровня; следующий уровень открывается после
  прохождения, цель стала недостижимой — уровень заканчивается сразу.
- **♾ Выживание** — 3 мяча, промах — минус мяч, каждые 5 очков — +1 мяч. Попадание 1 очко, чистое +1, серия: с 3-го
  попадания подряд ×2, с 6-го ×3 … до ×5 (если не тянуть с броском дольше 4 секунд — полоска на значке серии). После
  броска — новая точка; со счётом растут дистанция, ветер, движение кольца, появляются препятствия.
- **⏱ На время** — 60 секунд, мячей сколько угодно, следующий бросок — не дожидаясь предыдущего. Попадание 2 очка,
  из-за дуги (от 6,75 м) 3, чистое +1; серия: с 3-го попадания подряд ×2, с 6-го ×3. После попадания точка меняется;
  последние 20 секунд кольцо ездит.
- **💰 Конкурс трёхочковых** — 5 стоек по 5 мячей (углы 6,6 м, крылья и верх 6,75 м — FIBA), 60 секунд. Обычный мяч —
  1 очко, последний мяч каждой стойки — «денежный», 2 очка; одна стойка по выбору (на схеме площадки) — вся из
  денежных; максимум 34 очка. Мяч, выпущенный до сирены, засчитывается.
- **Управление:** перетаскивание мышью или пальцем в любом месте поля (в настройках — «тянуть назад» или «вести к
  цели»); короткая оттяжка или оттяжка не в ту сторону — отмена. Сила видна сразу в трёх местах: полоса под полем
  (%, угол, отметка прошлого броска), кольцо вокруг мяча и стрелка направления. Клавиатура: ← → — угол (с Shift — по
  5°), ↑ ↓ — сила, пробел или Enter — бросок, P / Esc — пауза. Подсказка траектории: полная (до первого касания; у
  движущегося кольца — «призрак» кольца в момент прилёта), короткая (начало полёта) или выключена — в настройках и
  на паузе, на части уровней ограничена; тонкая линия — след прошлого броска с этой же точки. Альбомная ориентация:
  показатели и полоса силы — колонкой слева, поле во всю высоту. При сворачивании вкладки — пауза.
- **Статистика** по режимам и всего: игры, броски, попадания, точность, чистые, от щита, лучшая серия, рекорды, время;

  полная стойка в конкурсе, 20 в конкурсе, 25 попаданий без подсказки) с прогрессом; новое достижение во время игры —
  короткая надпись на поле и значок в окне итогов (до трёх значков и «+N»; тосты — только в меню); **история**
  последних 60 игр.
- **Настройки:** звук, вибрация, подсказка траектории, способ броска, мяч (6 расцветок), сброс прогресса (с
  подтверждением; настройки остаются).
- **Проверка:** `test_phys.js` — ~44 000 бросков по сетке

  геометрическим пересчётом по трассе подшагов: ни одного прохода сквозь дужку, крепление и щит, засчитывание,
  «чистые» и «от щита» совпадают, мячи снизу не засчитываются, на 30/60/90/120/144/240 Гц и при «рваных» кадрах
  состояние совпадает бит в бит, подсказка совпадает с полётом; `solve_levels.js` — перебор угла и силы находит
  попадания, засчитываемые в цель, для каждого сочетания «точка + ветер» каждого из 30 уровней (и для всех фаз

### 🔢 2048

| | |
|---|---|
| **Файл** | `apps/2048.html` |
| **Категория** | 🧩 Головоломки |
| **Описание** | 2048 по правилам оригинала: поля 3×3–6×6, режимы «Классика», «На время» и «Без отмены», рекорды по полю и режиму, статистика и достижения |

- **Правила (как в оригинале):** ход сдвигает все плитки до упора; одинаковые сливаются, каждая плитка — не больше
  одного раза за ход (`2 2 2 2` → `4 4`), пары сливаются начиная от стены, к которой идёт ход (`2 2 2 ·` влево →
  `4 2`, вправо → `· · 2 4`; `4 2 2 ·` → `4 4`; `2 2 4 4` → `4 8`). После каждого хода, который что-то сдвинул,
  в случайной пустой клетке появляется 2 (90 %) или 4 (10 %); ход «в стену» не считается. Конец — когда нет пустых
  клеток и соседних одинаковых плиток. После цели — «Играть дальше» без ограничения.
- **Поля:** 3×3, 4×4, 5×5, 6×6. Цели по полю: 3×3 — 128…1024 (по умолчанию 256: больше 1024 там собрать нельзя),
  4×4 — 512…8192 (по умолчанию 2048, как раньше), 5×5 — 1024…16384, 6×6 — 2048…32768 (по умолчанию 2048).
- **Режимы:** **🧩 Классика** — 3 отмены хода за партию, рекорд засчитывается; дальше отменять можно, но партия
  становится тренировкой (без рекордов, статистики и достижений, с пометкой в истории). Отмена не перебрасывает
  случайность: новая плитка задаётся зерном партии, номером хода и полем, поэтому «отменить и повторить тот же ход»
  даёт ту же плитку. **⏱ На время** — 3 минуты на очки: время идёт с первого хода, на паузе стоит, а поле скрыто;
  без отмены и цели; если ходы кончились раньше — партия окончена. **🔥 Без отмены** — ни одной отмены, свой рекорд.
- **Анимации:** ход применяется к состоянию сразу, поле проигрывает очередь ходов — быстрые нажатия и свайпы подряд
  не теряются, анимация ускоряется и догоняет; плавный сдвиг (по времени, не по кадрам — одинаково на 60/120 Гц),
  «пульс» при слиянии (слившиеся плитки гаснут под новой — без дыры), появление новой плитки, «упор» поля при ходе
  в стену, «+N» у счёта, салют при победе. Настройка: плавные / быстрые / выключены.
- **Управление:** свайп по полю (пальцем; мышью — перетаскивание; ход срабатывает, как только палец прошёл порог),
  стрелки / WASD / цифровой блок (по физической клавише — работает и в русской раскладке; удержание клавиши не
  повторяет ход), Z / U / Backspace — отмена, P / Esc — пауза, R — новая игра, Enter — главная кнопка окна.
  Свайпы — только на зоне поля, меню прокручивается. При сворачивании вкладки — пауза.
- **Сохранение:** незаконченная партия — отдельно для каждого поля и режима (12 слотов), после каждого хода; точка
  на кнопке поля/режима — есть сохранённая партия; «Продолжить» в меню. Новая игра поверх сохранённой — с
  подтверждением, прерванная партия засчитывается («прервана»).
- **Рекорды** (лучший счёт и лучшая плитка) — по полю и режиму, обновляются по ходу партии (кроме тренировки).
- **Статистика** по полю и режиму: партии, лучший счёт и плитка, средний счёт, цель собрана (для «На время» — ходов
  в минуту), ходы, время; распределение лучших плиток партий (сколько партий и какая доля дошла хотя бы до плитки);
  итоги по всем партиям. **15 достижений** (плитки 256…8192, «В тесноте» — 256 на 3×3, «Без страховки» — 2048 без
  отмены на 4×4, «Блиц» и «Скорострел» на время, 5 слияний одним ходом, 1 000 ходов, 128 на всех полях, 25 партий),
  **история** последних 60 партий.
- **Настройки:** звук, вибрация, анимации, палитра плиток («Неон» / «Классика» — цвета оригинала); сброс прогресса
  (только из меню, диалог набора).
- **Очки на платформу:** не отправляются — как и в прежней версии (вызов `submitScore` пропал при переписывании
  файла в апреле 2026, коммит d6d5823); новых отправок не добавлено.
- **Хранилище** (`localStorage`): `g2048_settings`, `g2048_stats` (рекорды и статистика по слотам `3c`…`6h`),
  `g2048_ach`, `g2048_history`, `g2048_save_<поле><режим>` (например `g2048_save_4c`, `g2048_save_5t`).
  Ключи прежней версии: `bestScore2048` — рекорд переносится в «4×4 · Классика» и дальше обновляется;
  `theme2048` (палитра) и `targetValue2048` (цель 4×4) — читаются и обновляются; `gameState2048` (партия) переносится
  в слот `g2048_save_4c` и удаляется вместе с `tileIdCounter2048`. Испорченные данные проверяются и отбрасываются.

### 🔀 Пятнашки

| | |
|---|---|
| **Файл** | `apps/fifteen.html` |
| **Категория** | 🧩 Головоломки |
| **Описание** | Пятнашки 3×3–6×6: числа и неоновые картинки, пятнашки дня, подсказки от решателя (IDA*), показ решения, рекорды по ходам и по времени, статистика и достижения |

- **Правила:** расставить плитки по порядку слева направо и сверху вниз, пустая клетка — в правом нижнем углу
  (в режиме «Картинка» — собрать рисунок). Раскладка всегда решаема: проверяется чётность перестановки, для чётной
  ширины — с учётом ряда пустой клетки (снизу). Раскладка равномерно случайная среди решаемых и хорошо перемешана:
  почти собранные отбрасываются (на месте не больше 2–3 плиток, оценка «манхэттен + linear conflict» не ниже
  ~10-го перцентиля; на 3×3 кратчайшее решение — не меньше 16 ходов).
- **Поля:** 3×3 (8 плиток), 4×4 (15, классика), 5×5 (24), 6×6 (35). Цвет числа — цвет ряда, где плитка должна
  стоять; плитка на своём месте загорается.
- **Режимы:** **🔢 Числа**; **🖼 Картинка** — шесть неоновых сюжетов, нарисованных кодом на canvas без внешних файлов
  (Закат, Город, Волны, Космос, Мозаика, Фигуры; рисунок задаётся сюжетом и зерном — у каждой партии свой вариант, или
  🎲 случайный), номера-подсказки в углу плиток включаются кнопкой **#** (N), **👁 Образец** (удерживать, V) показывает
  целый рисунок, при сборке проявляется недостающий кусочек; **📅 Пятнашки дня** — одна раскладка 4×4 в день, одинаковая
  у всех (зерно от даты), засчитывается первая сборка дня, серия 🔥, повтор — тренировка без статистики.
- **Ход и управление:** тап (клик) по плитке в одном ряду или столбце с пустой клеткой сдвигает сразу все плитки
  между ними; свайп по полю (палец или перетаскивание мышью) двигает соседнюю с пустой плитку в сторону свайпа;
  стрелки / WASD / цифровой блок (по физической клавише — и в русской раскладке). Ходы считаются по плиткам (сдвиг трёх
  плиток — 3 хода). Ход применяется сразу, поле проигрывает очередь ходов — быстрые нажатия не теряются, анимация
  ускоряется и догоняет; анимация и часы идут по времени, а не по кадрам (одинаково на 30/60/120+ Гц). H — подсказка,
  P / Esc — пауза, R — новая раскладка, Enter — главная кнопка окна.
- **Подсказка 💡** — следующий ход из текущей позиции (подсвечена плитка, стрелка в пустой клетке, «до сборки N ходов»):
  3×3 — кратчайшее решение (IDA*); 4×4 — IDA* по манхэттену + linear conflict (таблицы конфликтов) с лимитом 1,2 с,
  не успел — взвешенный IDA* (в среднем +13 % к оптимуму) или послойный решатель, берётся кратчайшее; 5×5 и 6×6 —
  послойный (ряд и столбец по очереди: плитки по одной, последние две — парой, поиском в ширину; остаток 3×3 —
  оптимально, 4×4 — быстрым поиском; лучший из четырёх вариантов). Решатель работает в фоновом потоке (Web Worker из
  той же функции движка), без потока — в основном с урезанным лимитом. План кэшируется: каждая подсказка по нему
  сокращает остаток, поэтому «подсказка за подсказкой» всегда доводит до сборки. Партия с подсказкой засчитывается
  собранной с пометкой 💡, но без рекорда (первую подсказку игра подтверждает).
- **🤖 Решение** — компьютер собирает головоломку из текущей позиции с анимацией (4×4 — до 2,5 с на поиск кратчайшего);
  останавливается кнопкой «Стоп» или ходом игрока, на паузе ждёт. Такая партия не засчитывается (в истории —
  «решение показано»).
- **Время и пауза:** время идёт с первого хода; на паузе, в окнах и при скрытии вкладки стоит, а поле скрыто.
- **Рекорды** — отдельно для каждого поля и режима (и для пятнашек дня): наименьшее число ходов и лучшее время
  (с десятыми) — это могут быть разные партии; только сборки без подсказок.
- **Статистика** по полю и режиму: партии, собрано (%), рекорды, среднее время и ходы, с подсказкой, показано решений,
  5 лучших времён; пятнашки дня (дней, серия, лучшая серия, рекорды); итоги. **15 достижений** (первая сборка, каждое
  поле без подсказок, «Молния» — 3×3 быстрее 20 с, «Скорость» — 4×4 быстрее 1:30, «Экономно» — 4×4 за ≤150 ходов,
  «Идеально» — 3×3 за кратчайшее число ходов, «Художник», «Чистое искусство» — картинка ≥4×4 без номеров, пятнашки дня,
  неделя подряд, все поля, 25 сборок) — новые показываются значками в окне итогов. **История** последних 60 партий.
- **Сохранение:** незаконченная партия — отдельно для каждого поля и режима и для пятнашек дня, после каждого хода и
  при сворачивании; точка на кнопке поля/режима и «Продолжить» в меню. Новая раскладка поверх партии — с
  подтверждением, прежняя попадает в историю как брошенная.
- **Настройки:** звук, вибрация, анимации (плавные / быстрые / выкл), номера на картинке; сброс прогресса (из меню).
- **Очки на платформу:** не отправляются — прежняя версия игры тоже не вызывала `submitScore`; новых отправок не
  добавлено.
- **Хранилище** (`localStorage`): `fifteen_settings`, `fifteen_stats` (рекорды и статистика по слотам `3n`…`6n`,
  `3p`…`6p`, `daily`; серия дня), `fifteen_ach`, `fifteen_history`, `fifteen_save_<слот>` (например
  `fifteen_save_4n`, `fifteen_save_5p`, `fifteen_save_daily`). Ключи прежней версии `15best` (рекорд ходов 4×4) и
  `15stats` (`solved`, `bestTime` в секундах) переносятся один раз в «4×4 · Числа» и дальше обновляются. Испорченные
  данные проверяются и отбрасываются (нерешаемая или неверная сохранённая раскладка удаляется).

### 🔲 Судоку

| | |
|---|---|
| **Файл** | `apps/sudoku.html` |
| **Категория** | 🧩 Головоломки |
| **Описание** | 6 версий, 4 сложности, судоку дня, кампания и дуэль — вдвоём или по сети |

- **Версии:** Классика 9×9; Мини 6×6 (цифры 1–6, блоки 2×3, три сложности); Диагональ (обе диагонали без повторов);
  Гипер (ещё четыре окна 3×3); Пазл (фигурные блоки); Киллер (клетки-суммы: пунктир и сумма в углу).
- **Сложность — по приёмам**, а не по числу открытых цифр. Встроенный «человеческий» решатель: одиночки; указывающие
  группы и «блок и линия»; голые и скрытые пары и тройки; X-Wing, Y-Wing, рыба-меч; для киллера — комбинации сумм,
  обязательная цифра суммы, правило 45 для строки, столбца, блока и полос из 2–3 строк (столбцов). Лёгкий — хватает
  одиночек, Средний — указывающие группы (в киллере — суммы и правило 45), Сложный — пары, Эксперт — тройки, X-Wing,
  Y-Wing, рыба-меч (в киллере — полосы и пары). У каждой головоломки одно решение, и решатель проходит её до конца без перебора.
- **Генерация** — в фоновом потоке (Web Worker из той же функции-движка; если поток недоступен — кусками по 14 мс),
  обычно 0,05–1 с; одна головоломка последней выбранной версии готовится заранее. Генерация по зерну: судоку дня и
  уровни кампании одинаковые на всех устройствах.
- **Режимы:** Новая игра; Судоку дня — одна в день, версия по дню недели, серия 🔥 и полоска недели в меню; Кампания —
  6 глав по 8 уровней (мини → классика → диагональ → гипер → пазл → киллер), звёзды, глава открывается после 3 уровней
  предыдущей; Дуэль — вдвоём на одном устройстве или по сети (KuNet): по очереди по одной цифре в общее поле, верная +10,
  за каждую заполненную строку, столбец или блок ещё +5, ошибка −5.
- **Ввод:** клетка → цифра или «сначала цифра» (настройка); заметки, автозаметки (все кандидаты), отмена, стереть;
  верная цифра убирает себя из заметок соседей; под цифрами — сколько их осталось поставить. Клавиатура: 1–9,
  Shift+цифра — заметка, стрелки, Backspace / Delete, N — заметки, A — автозаметки, Z / U / Ctrl+Z — отмена,
  H — подсказка, Enter — применить её, P / Esc — пауза.
- **Подсказка** — следующий логический шаг: подсвечивает область и клетки приёма, объясняет его (с исключениями,
  без которых шаг не увидеть) и предлагает «Поставить» или «Сам поставлю». В режиме «не проверять» сначала показывает
  неверную цифру. На маленьком экране панель поднимается над полем, но не закрывает нужную клетку.
- **Проверка ошибок:** сразу (красным; лимит 3 / 5 / без лимита) или не проверять (заполненное поле с ошибкой
  считается ошибкой, подсказка покажет где). Дошли до лимита — можно продолжить: неверные цифры убираются, лимит
  вырастает на одну ошибку. Подсветка конфликтов, области выбранной клетки и одинаковых цифр, скрытие закончившихся
  цифр, таймер, звук — в настройках. В паузе — «Очистить поле» (свои цифры и заметки стираются, время, ошибки и
  подсказки сохраняются, очистку можно отменить).
- **Очки:** база по сложности (100 / 200 / 350 / 500) × множитель версии (мини 0,5 … киллер 1,5), бонус за скорость
  относительно норматива, −10 % за ошибку, −15 % за подсказку → `PlatformAPI.gameplay.submitScore('sudoku', …)`.
  Звёзды: ★★★ — без ошибок и подсказок не дольше норматива, ★★ — не больше 1 ошибки и 1 подсказки и не дольше 1,5 норматива.
  Одну головоломку нельзя «доить»: повтор решённого судоку дня — без очков, повтор уровня кампании — только прирост
  к лучшему результату уровня.
- **Статистика** по версиям и сложностям (сыграно, решено, рекорд, среднее время, серия); партия сохраняется
  автоматически и продолжается из меню; рекорды и сохранённая партия прежней версии игры переносятся.
- **Дуэль по сети:** лобби открывается сразу, головоломку готовит создатель комнаты; состояние комнаты от соперника
  проверяется целиком (головоломка, исходные цифры, верность цифр, очки и очередь хода) — испорченное не применяется.
- **Доступность:** поле — `role="grid"` со строками и `aria-activedescendant`, у клеток — подписи (строка, столбец,
  цифра или заметки); окна — `role="dialog"`, фокус переходит в окно и возвращается, Tab не уходит под окно.
- **Хранилище** (`localStorage`): `sudoku2_settings`, `sudoku2_stats`, `sudoku2_camp`, `sudoku2_save`,
  `sudoku2_pool`, `sudoku2_cache`, `sudoku2_sent` (уже отправленные очки за уровни кампании и дни — «Сбросить
  статистику» его не трогает, чтобы известные головоломки не давали очки повторно).

### 💣 Сапёр

| **Файл** | `apps/minesweeper.html` |
| **Категория** | 🧩 Головоломки |
| **Описание** | Классический сапёр по всем правилам: 3 уровня и своё поле, поля без угадывания, сапёр дня, подсказки с объяснением |

- **Подсказка 💡** — следующий логический шаг с подсветкой чисел-оснований и объяснением; находит неверный флаг;

  норматива поля (3BV × 1,6 с + 10 с), от ×0,4 до ×2; подсказка −30 %; сапёр дня ×1,5 только за первую победу дня

- **Клавиши:** стрелки / WASD — курсор, пробел / Enter — открыть (у числа — соседей), F — флаг, H — подсказка,

### 🔤 Слово (Вордл)

| | |
|---|---|
| **Файл** | `apps/wordle.html` |
| **Категория** | 🧠 Логика |
| **Описание** | Вордл по-русски: угадать существительное из 4–7 букв за 6 попыток. «Слово дня» (одно на день у всех, серия дней) и свободная игра, сложный режим, статистика по длине и режиму, «Поделиться», 14 достижений, история |

- **Правила (как в оригинале):** попытка — существительное в начальной форме (им. п., ед. ч.) из словаря игры;
  слова нет в словаре — «Нет в словаре», строка дрожит, попытка не тратится; слово короче нужного или уже
  было — тоже не засчитывается. Цвета: 🟩 буква на месте, 🟨 есть в слове в другом месте, ⬛ нет в слове.
  **Повторы букв:** сначала отмечаются зелёные, затем жёлтые — слева направо и не больше раз, чем такая буква
  осталась в загаданном слове (загадано ВАГОН, попытка КАБАН → вторая «А» серая). Экранная клавиатура
  показывает лучший цвет каждой буквы. **Ё = Е** (вводится и показывается как Е).
- **Длина слова 4, 5, 6 или 7 букв** (выбор в меню), всегда 6 попыток. Словарь (загадываемые / всего допустимых):
  4 буквы — 780 / 1 888, 5 букв — 971 / 4 036, 6 букв — 1 347 / 5 786, 7 букв — 1 454 / 7 508.
- **Режимы.** **📅 Слово дня** — одно слово на календарный день (по часам устройства) для каждой длины,
  одинаковое у всех: постоянная перестановка списка загадываемых слов (зерно — длина слова), день № d берёт
  слово d mod N — за цикл из N дней (780–1 454) каждое слово ровно один раз, повтор не раньше чем через N дней.
  Номер дня — с 23.10.2026 (№1). Сыграть можно **один раз**: партия сохраняется после каждой попытки,
  перезагрузка продолжает её, законченную — только посмотреть (итоги и «Поделиться»). Доигранное после
  полуночи засчитывается своим днём; недоигранное до полуночи (с попытками) — поражение. **Серия дней** —
  подряд отгаданные дни; пропуск дня или проигрыш обнуляют её. **🎲 Свободная игра** — сколько угодно слов,
  недавние (до 200 на длину) и сегодняшнее слово дня не загадываются; «Другое слово» до первой попытки —
  без последствий, «Сдаться» после попыток — поражение.
- **Сложный режим** (настройка): открытые подсказки обязательны — зелёные буквы на своих местах, жёлтые
  (и зелёные) в слове не меньше раз, чем открыто в одной попытке; серые использовать можно. Нарушение —
  сообщение с правилом («Сложный режим: 2-я буква должна быть «А»», «…не меньше 2 букв «А»»). Включается
  до первой попытки, иначе — со следующего слова; в «Поделиться» отмечается звёздочкой.
- **Статистика** отдельно по каждой длине и режиму: сыграно, % побед, текущая и лучшая серия, распределение
  попыток (гистограмма, последняя партия подсвечена); итоги: партии, угадано слов, слов дня, лучшая серия,
  достижения, время в игре. В окне итогов — слово, попытки, время, серия, % побед, распределение, новые
  достижения, у слова дня — отсчёт до следующего.
- **📤 Поделиться** — текст без букв, например `Слово дня №12 · 5 букв · 4/6*` и строки 🟩🟨⬛ (в режиме
  контрастности 🟧🟦⬛). Копирование: Clipboard API → запасной способ (`execCommand('copy')`, работает
  в iframe без разрешения на буфер) → окно с выделенным текстом для ручного копирования.
- **Удобство и доступность:** экранная клавиатура ЙЦУКЕН (ВВОД, ⌫) подстраивается под экран — на 360×640 и
  390×844 плитки 42–66 px, клавиши от 25×41 px; в альбомной ориентации (844×390) поле слева, клавиатура
  справа (7 букв: плитки 44 px, клавиши 34×54 px). Анимации: появление буквы, тряска строки, переворот плиток
  по очереди, «подпрыгивание» при победе — выключаются настройкой и системным «уменьшить движение».
  **Высокая контрастность** — оранжевый и синий вместо зелёного и жёлтого. Для экранных дикторов: результат
  каждой строки, ошибки и итог объявляются через `aria-live`, у строк и клавиш — подписи со статусом букв;
  фокус не уходит из открытого окна. Незаконченная партия (свободная — по каждой длине, и слово дня)
  сохраняется после каждой попытки и набранных букв — «▶ Продолжить» в меню; пауза и сохранение при
  сворачивании вкладки, время партии на паузе стоит.
- **14 достижений:** первое слово, с первой попытки, за две, с шестой, 5 и 15 побед подряд, слово дня,
  7 дней подряд, победа в сложном режиме, 7 букв в сложном режиме, все длины, 7 букв за ≤3 попытки, 50 и 200
  слов (накопленное прежней версией открывается само). **История** последних 100 партий: слово, режим, длина,
  мини-сетка цветов, результат, дата и время.
- **Настройки:** сложный режим, высокая контрастность, анимации, звуки, вибрация; сброс статистики
  (только из меню, с подтверждением).
- **Управление:** экранная клавиатура или обычная — русская раскладка, а при латинской — по местам ЙЦУКЕН
  (Q → Й, W → Ц …); Enter — проверить, Backspace — стереть, Esc — пауза (на законченном поле Enter/Esc —
  итоги).
- **Очки на платформу:** не отправляются — игра не вызывала `submitScore` и в прежней версии; новых
  отправок не добавлено.
- **Хранилище** (`localStorage`): `wordle_stats` — статистика прежней версии (при первом запуске переносится
  в «свободную игру, 5 букв»: сыграно, победы, серии, распределение, список недавних слов; сам ключ не
  меняется), `wordle_stats2` (статистика по режиму и длине, недавние слова), `wordle_daily` (попытки и итоги
  «Слова дня» по датам, 60 дней), `wordle_save` (незаконченные свободные партии), `wordle_settings`,
  `wordle_ach`, `wordle_history`. Испорченные данные проверяются и отбрасываются; без доступа к хранилищу
  игра работает в памяти.
- **Словарь — источники.** Загадываемые 5 букв — прежний список игры; 4, 6 и 7 букв — ручная выборка частых
  нарицательных существительных (без имён собственных, жаргона, грубых и оскорбительных слов; названия групп
  людей по политике, религии и происхождению, слова о мигрантах и церковные звания не загадываются, но остаются
  допустимыми попытками)
  из частотного списка [wordfreq](https://github.com/rspeer/wordfreq) 3.1.1 (данные — CC BY-SA 4.0)
  с морфологическим разбором [pymorphy3](https://github.com/no-plagiarism/pymorphy3) и словарём
  OpenCorpora (`pymorphy3-dicts-ru` 2.4.417150, CC BY-SA 3.0). Допустимые попытки — загадываемые плюс все
  нарицательные существительные этой длины в им. п. ед. ч. из словаря OpenCorpora и прежний список игры,
  без мата и этнических оскорблений. Порядок списка загадываемых задаёт последовательность «Слова дня» —
  при изменении списка слова дня меняются.

### 🃏 Найди пару (Мемори)

| **Категория** | 🧩 Головоломки |
| **Описание** | Мемори по классическим правилам: 5 полей (4×3–6×6), 7 наборов карт, режимы «Классика», «На время», «Лимит ходов», «Вдвоём» и «Испытание дня»; рекорды ходов и времени по полю, статистика, достижения |

- **Правила:** ход — открыть две карты. Совпали — пара остаётся открытой, нет — обе закрываются через короткую
  паузу (0,6 / 0,9 / 1,4 с — настройка). Не хотите ждать — сразу открывайте следующую карту: несовпавшая пара
  закрывается мгновенно. Повторное нажатие на открытую или найденную карту и на показываемую пару ничего не делает
  (двойные тапы и щелчки не ломают ход). Время идёт с первой открытой карты и стоит на паузе. **Промах по памяти** —
  пара первой карты уже открывалась раньше, а вторая открыта не та; **точность** — пары ÷ ходы.
- **Поля:** 4×3 (6 пар), 4×4 (8), 5×4 (10), 6×5 (15), 6×6 (18). Раскладка подбирается под экран: на узком экране поле
  поворачивается (ряды ↔ столбцы, соседство карт сохраняется — и при повороте телефона посреди партии), карты
  вытягиваются по высоте до 1,3 к ширине. Карты 6×6: 55×72 px на 390×844, 50×65 на 360×640, 56×45 в альбоме 844×390.
- **Наборы карт** (в партии — случайные символы набора): 🏋️ Спорт (прежний), 🐼 Животные, 🍕 Еда, 🚗 Транспорт,
  🇰🇬 Флаги (только если устройство рисует флаги — на Windows они выглядят буквами, тогда набор скрыт), ⭐ Символы,
  😵 Смайлы — сложный набор из похожих лиц.
- **Режимы:** **🎮 Классика** — без ограничений. **⏱ На время** — успеть до конца отсчёта: 35 / 45 / 60 / 100 / 130 с
  (4×3 … 6×6), отсчёт с первой карты, последние 10 с — красным, последние 5 — тиканье. **🧮 Лимит ходов**
  (ограниченные ходы) — 11 / 16 / 21 / 36 / 46 ходов: идеальная память укладывается всегда (худший случай
  11 / 14 / 18 / 27 / 31), модель «обычного» игрока — примерно в 70 % партий. **👥 Вдвоём** — по очереди на одном
  устройстве: пара — ещё ход, промах — ход переходит (следующий игрок может сразу открывать карту), счёт пар, ничья;
  пары подсвечены цветом игрока (жёлтый / розовый), первый ход в следующей партии — у другого.
  **📅 Испытание дня** — одна раскладка на дату у всех (зерно даты), размер по дню недели (пн 4×4, вт 5×4, ср 6×5,
  чт 4×4, пт 5×4, сб 6×5, вс 6×6), набор — по дате; засчитывается первая попытка, повторы — тренировка; серия дней,
  «Скопировать результат».
- **Анимации:** 3D-переворот, совпадение — вспышка и свечение, промах — красный цвет и лёгкая тряска, «🔥 ×N» над
  картой при серии пар, каскад при победе, показ всех карт при проигрыше; при «уменьшить движение» — без анимаций.
- **Доступность:** карты — кнопки с подписями для экранных дикторов («Ряд 2, карта 3: собака, пара найдена»),
  ходы объявляются через `aria-live`; фокус не уходит из открытого окна и возвращается на кнопку, которая его открыла.
- **Управление:** тап / щелчок по карте; стрелки / WASD — выбрать карту (с учётом поворота поля), Enter / пробел —
  открыть (удержание не повторяет), P / Esc — пауза, R — заново. Второй тап двойного нажатия «Играть» /
  «Продолжить» не открывает карту под пальцем.
- **Пауза и сохранение:** на паузе время стоит, а все карты лежат рубашкой вверх; пауза при сворачивании вкладки;
  вопрос «Заново?» тоже останавливает время и скрывает карты. Незаконченная партия сохраняется после каждого хода —
  «▶ Продолжить» в меню (и после перезапуска), время продолжается со следующей карты. Новая партия поверх
  незаконченной — с подтверждением и засчитывается как прерванная.
- **Рекорды:** для каждого поля отдельно — меньше всего ходов и лучшее время (могут быть из разных партий);
  засчитываются победы в классике, на время, с лимитом ходов и первая попытка испытания дня (не «Вдвоём», не тренировка).
- **Статистика:** партии, победы и %, найдено пар, точность, лучшая серия, время в игре, рекорды по полям, итоги по
  режимам («Вдвоём» — победы игроков и ничьи), прерванные партии, промахи по памяти. **15 достижений** (первая
  победа, 6×6, все размеры, фотографическая память, 5 пар подряд, 4×4 быстрее 25 с, «На время» и «на последней
  секунде», лимит на 6×5+, партия вдвоём, ничья, испытание дня и 7 дней подряд, 5 наборов, 50 побед) — новые
  показываются в окне итогов; **история** последних 50 партий.
- **Настройки:** время показа несовпавших карт, звуки, вибрация; сброс прогресса (только из меню, диалог набора).
- **Очки на платформу:** не отправляются — игра не вызывала `submitScore` ни в одной версии; новых отправок не добавлено.
- **Хранилище** (`localStorage`): `memory_best` — рекорды по полю в формате прежней версии
  (`{ "8": { tries, time, wins } }`; прежние поля 3×4 и 4×5 — это 4×3 и 5×4 с тем же числом пар, рекорды
  сохраняются), `memory_size` — выбранное поле (ключ прежней версии), `memory_settings`, `memory_stats` (при первом
  запуске прежние победы переносятся в статистику), `memory_ach`, `memory_history`, `memory_save` (незаконченная
  партия), `memory_daily` (попытки, результаты и серия испытания дня). Испорченные данные проверяются и отбрасываются.

### ✕○ Крестики-нолики

| | |
|---|---|
| **Файл** | `apps/tictac.html` |
| **Категория** | 🧠 Логика |
| **Описание** | Крестики-нолики в пяти вариантах — 3×3, 4×4, 5×5, гомоку 15×15 и ультимативные; ИИ трёх уровней, вдвоём на одном устройстве и по сети |

- **Варианты:** 3×3 (три в ряд); 4×4 (четыре в ряд — вся строка, столбец или диагональ); 5×5 (четыре в ряд, пять подряд —
  тоже победа); **гомоку 15×15** — пять в ряд по правилу «пять и больше» (длинный ряд из 6+ знаков тоже побеждает);
  **ультимативные** — 9 малых полей: клетка хода отправляет соперника в малое поле с тем же положением, выигранное или
  заполненное поле закрыто (ход туда невозможен, «отправка» в него — свободный выбор любого открытого поля), ничья в
  малом поле не засчитывается никому, победа — три малых поля в ряд, все поля закрыты без ряда — ничья.
  ✕ всегда ходит первым; ряд проверяется по строке/столбцу (без «перехода через край»).
- **ИИ (3 уровня):** 🌱 лёгкий часто ошибается; ⚔️ средний всегда забирает свой ряд, обычно (≈85–90 %) закрывает угрозу,
  не видит «вилок»; 🔥 сложный: на 3×3 — полный перебор (непобедим), из равноценных ходов выбирает разные, с весом по
  «ловушечности» (вероятности ошибки соперника); на 4×4 / 5×5 / гомоку — немедленный ряд и обязательный блок, поиск
  форсированной победы сплошными «четвёрками» (свой и соперника — с поиском опровергающих ходов), в гомоку — защита от
  атак тройками и «вилок» (3×3, 4×3), альфа-бета с итеративным углублением по оценке окон (тройки, открытые четвёрки,
  двойные угрозы); в ультимативных — Монте-Карло (UCT)
  с тактическим фильтром (выигрыш партии сразу, никаких ходов, отдающих сопернику немедленную победу). Расчёт — в Web
  Worker (интерфейс не замирает), бюджет хода 0,5–0,75 с; если поток недоступен — в основном потоке с бюджетом 0,22 с.
- **Режимы:** против ИИ; вдвоём на одном устройстве; по сети с другом (KuNet). «Кто играет ✕»: я / соперник / по
  очереди (стороны меняются каждую партию). Счёт серии (Вы · Ничьи · Соперник) — в шапке, «↺ Сбросить счёт серии» — в паузе.
- **По сети:** 3×3 — прежний идентификатор `tictac` и прежний формат состояния `{board, current}` (✕ у создателя
  комнаты), поэтому в одной комнате могут играть новая и старая (из кэша) версии игры. Остальные варианты — свои
  идентификаторы `tictac_4`, `tictac_5`, `tictac_g15`, `tictac_u` (старые клиенты их не видят) и формат
  `{v: 2, g, m: строка клеток, x: место ✕, n, l: последний ход}`; стороны меняются каждую партию. Вход по коду сам
  переключает на вариант комнаты; чужая комната (другой игры) — выход с сообщением; если в новом варианте соперник
  с начала партии молчит 50 с — подсказка, что у него, возможно, старая версия.
- **Удобство:** подсветка последнего хода (настройка), выигрышная линия, в ультимативных — подсветка поля, куда надо
  ходить; ↶ отмена хода (против ИИ — до вашего последнего хода, вдвоём — один ход); 💡 подсказка (ход сильного ИИ);
  гомоку на телефоне — клетки не мельче 22 px, кнопки − / + (31 и 40 px) с прокруткой поля пальцем, на сенсорном экране
  ход подтверждается вторым тапом (первый — отметка с подсветкой строки и столбца; настройка «Авто / Всегда / Нет»);
  альбомная ориентация — панель слева, поле справа; пауза при скрытии вкладки (против ИИ и вдвоём).
- **Отмена и подсказка в статистике:** партия против ИИ с отменой или подсказкой — «с помощью»: её победа не идёт в
  победы, серии и достижения (видна отдельной строкой), ничья и поражение засчитываются как обычно. Незаконченная
  партия сохраняется («▶ Продолжить» в меню); новая партия поверх неё (или «Сдаться» в паузе) — поражение (с подтверждением).
- **Статистика** по варианту и сопернику (лёгкий / средний / сложный / вдвоём / по сети): партии, победы, ничьи,
  поражения, % побед, серия побед и лучшая, серия без поражений и лучшая, самая быстрая победа; **15 достижений**;
  **история** 60 последних партий с пошаговым просмотром.
- **Очки:** игра не отправляет очки на платформу (`submitScore` не вызывается — как и в прежней версии).
- **Клавиши:** стрелки — выбор клетки, Enter / пробел — ход, U (Ctrl+Z, Backspace) — отмена, H — подсказка,
  N — следующая партия, + / − — масштаб гомоку, P / Esc — пауза.
- **Хранилище** (`localStorage`): `tictac_settings`, `tictac_stats`, `tictac_ach`, `tictac_history`, `tictac_save`
  (незаконченная партия). Прежняя версия ничего не сохраняла (счёт серии жил в памяти); испорченные данные
  проверяются по полям и отбрасываются.

### 🚧 Wall Rush

| | |
|---|---|
| **Файл** | `apps/wallrush.html` |
| **Категория** | 🧠 Логика |
| **Описание** | Доведи фишку до дальнего ряда, до центра или первым до финиша в гонке, перекрывай путь сопернику стенами — против ИИ, вдвоём и по сети |

Стратегическая игра на поле 9×9 или на прямоугольной трассе 7×11 (механика в духе Quoridor). За ход — шаг фишкой
или одна стена; у каждого 10 стен. Стена закрывает две клетки, стены нельзя накладывать и пересекать, и нельзя
ставить так, чтобы полностью отрезать игрока от цели. Соперника рядом можно перепрыгнуть, а если за ним стена —
обойти по диагонали.

- **Цель игры (выбор в меню, запоминается):**
  - «К краю» — классика: фишки стартуют сверху и снизу, нужно дойти до дальнего ряда своего цвета;
  - «В центр» — красный стартует с левого края, синий с правого, побеждает первый, кто встанет на золотую клетку
    в центре. Центр нельзя замуровать стенами со всех сторон;
  - «🏁 Гонка» — трасса 7×11: обе фишки стартуют с общей линии старта внизу, финиш общий — клетчатый ряд наверху.
    Стены тормозят обоих — перекрывайте полосу соперника, не запирая себя. Стен 8 у красного и 9 у синего
    (компенсация за второй ход). В подписях игроков — сколько клеток до финиша (🏁 N).
- **Режимы:** против ИИ (Легко / Средне / Сложно — negamax с альфа-бета отсечением); вдвоём на одном телефоне
  (верхняя панель развёрнута к сопернику); по сети с другом (KuNet) — создатель комнаты играет красными, у второго
  игрока доска повёрнута на 180° (в гонке — нет: финиш у обоих сверху), цель игры берётся из комнаты, «Играть снова» —
  реванш для обоих. Формат состояния и хода (`{t:'m', r, c}` / `{t:'w', o, r, c}`) прежний — новая версия и прежняя
  (из кэша service worker) играют в одной комнате.
- **Ход:** щелчок или тап по подсвеченной клетке (под курсором клетка подсвечивается целиком).
- **Стена — без кнопки, прямо по пазу между клетками:**
  - *мышь* — при наведении на паз сразу виден призрак стены цвета игрока; щелчок ставит стену. Серый призрак с ✕ —
    сюда нельзя, причина — в подписи у кнопки стен (занято, пересекает или налезает на стену, отрежет соперника или
    вас от цели, замурует центр), при щелчке — сообщение. Середина стены — ближайшее пересечение пазов (у края поля
    стена сдвигается внутрь), рамка поля — не паз; если там стену поставить нельзя, а через тот же участок паза
    проходит стена, которую можно, — призрак сдвигается на неё (удобно ставить встык к уже стоящей). На пересечении
    пазов призрак держит направление, с которого пришёл курсор; повернуть — **R**, правая кнопка мыши или колесо;
  - *касание* — тап по пазу показывает призрак (ход не тратится), ещё тап по призраку или кнопка **✓** — поставить,
    **⟳** — повернуть; ведение пальцем по доске двигает призрак по пазам; тап по пустой клетке или мимо поля — убрать.
    Ход фишкой — по-прежнему один тап. Сам паз всегда за стеной: спорный тап даёт лишь призрак, который нужно
    подтвердить, а не необратимый ход. Зоны попадания: паз ± 20 % клетки для мыши и ± 30 % для пальца
    (≈ 24 px на 360×640);
  - *прежний способ* сохранён: тап по кнопке стен → провести по доске → отпустить (ориентацию задаёт направление);
  - пока ход не ваш (ИИ думает, ход соперника по сети) — призраков нет, щелчки ничего не ставят; стены кончились —
    призраков нет, щелчок по пазу — сообщение.
- **Кнопка стен** — счётчик оставшихся стен; ⟳ и ✓ рядом с ней появляются, пока стена выбрана касанием. В подписи
  у кнопки на первых своих ходах (до первой стены, не больше 3 ходов за сессию) — подсказка «стена — тап по пазу» /
  «стена — щелчок по пазу» по устройству ввода.
- **Клавиши:** стрелки — шаг фишкой (и прыжок через соседа; на повёрнутой доске — по экрану), R — повернуть призрак,
  Enter — поставить призрак, Esc — убрать призрак / пауза, U / Backspace / Ctrl+Z — отменить ход, P — пауза.
- **Отмена хода** кнопкой ↶ (против ИИ — до вашего хода, вдвоём — один ход; по сети недоступна). Пауза при
  скрытии вкладки (против ИИ и вдвоём).
- **Экран:** телефон в портрете — панели игроков над и под полем; телефон в альбоме — поле во всю высоту, заголовок
  и панели по бокам; анимация фишек не зависит от частоты кадров.
- **Статистика:** победы и поражения против ИИ по цели игры и уровню — в меню и в окне итогов.
- **Очки:** при победе над ИИ — `submitScore('wallrush', очки, XP = очки / 10 с округлением)`: база по уровню
  (100 / 250 / 500) + 15 за каждую оставшуюся стену + 3 × (60 − ваших ходов фишкой, не меньше 0). Вдвоём и по сети
  очки не отправляются.
- **Хранилище** (`localStorage`): `wallrush_stats` — `{easy|medium|hard: {w, l}}` для «к краю», `center_<уровень>` и
  `race_<уровень>` для других целей; `wallrush_mode` — выбранная цель игры. Испорченные данные (не объект, записи
  не того типа) отбрасываются и не ломают игру.

### 🧪 Сортировка цветов

| | |
|---|---|
| **Файл** | `apps/watersort.html` |
| **Категория** | 🧩 Головоломки |
| **Описание** | Переливай жидкости по цвету: 200 уровней в 8 главах, головоломка дня, свободная игра, звёзды за минимум ходов |

- **Правила:** переливается верхний слой — все подряд идущие сверху порции одного цвета, сколько поместится (остаток
  остаётся в пробирке); лить можно в пустую пробирку или на тот же цвет. Уровень решён, когда каждая пробирка пуста
  или заполнена одним цветом до верха; собранная пробирка закрывается пробкой. Слои «?» скрыты, пока не окажутся
  сверху; перелитая жидкость всегда видна.
- **Кампания:** 200 уровней, 8 глав по 25 — «Первые капли», «Тесная колба», «Тайные слои», «Пять слоёв», «Большая
  лаборатория», «Глубины», «Мастерская», «Великий алхимик». От 2 до 12 цветов, вместимость 4–5 слоёв, одна или две
  пустые пробирки, скрытые слои (часть или все, кроме верхних). В каждой главе своя новинка; уровни открываются по
  порядку. Выбор уровня — вкладки глав, звёзды и метки механик у каждого уровня.
- **Генератор по зерну:** уровень N одинаков у всех (ГПСЧ mulberry32 от строки-зерна, только целочисленные
  вычисления). Для уровня строится 5 кандидатов — решатель отбрасывает нерешаемые раскладки — и выбирается по
  «ловушечности» (сколько из 24 партий жадного полуслучайного игрока заходят в тупик): в начале главы — полегче, к
  концу — потруднее. Выбор записан таблицей «кандидат.попытка.минимум», поэтому уровень открывается мгновенно;
  тесты сверяют таблицу с полной генерацией.
- **Решатель:** A* по позициям (пробирки взаимозаменяемы; из собранной и однородной в пустую не льём; из пустых —
  одна) с допустимой эвристикой — каждый слой, лежащий на другом цвете, обязан сдвинуться, плюс лишние «донышки»
  одного цвета. Даёт точный минимум ходов (если не уложился в лимит — взвешенный A*). Работает кусками по ~8 мс:
  подсказки и проверки не подвешивают телефон.
- **Звёзды:** ★★★ — не больше «Цели ★★★»: минимум решателя (у крупных уровней +1 ход на каждые 15, при скрытых
  слоях ещё +10 %); ★★ — до цели +30 % (не меньше +2 ходов); ★ — решено. Ход — одно переливание, отменённые ходы
  не считаются. В окне победы — ходы, минимум решателя, время, лучший результат.
- **Помощь:** ↶ отмена без ограничений; ↻ начать заново; 💡 подсказка — первый ход кратчайшего решения из текущей
  позиции (3 на попытку). После каждого хода решатель в фоне проверяет позицию: если решения больше нет, игра
  пишет «Тупик» и предлагает отменить ровно столько ходов, сколько нужно до решаемой позиции. ＋ Пробирка — пустая
  пробирка один раз за попытку, тогда за уровень максимум ★★.
- **Головоломка дня:** одна на день, одинаковая у всех (в будни полегче, в воскресенье — 12 цветов со скрытыми
  слоями), серия дней. **Свободная игра:** случайные головоломки с выбранными параметрами (цветов 2–12, слоёв 4/5,
  пустых 1/2, скрытые слои: нет / часть / все) и 4 пресета; N или 🎲 — новая.
- **Статистика** (кампания, главы, головоломка дня, итоги) и **15 достижений**. Незаконченная партия сохраняется
  отдельно для каждого режима и продолжается после перезапуска.
- **Управление:** тап по пробирке — выбрать, по другой — перелить (наклон и струя); невозможный ход — тряска и
  объяснение; двойной тап или удержание — авто-перелив. Пробирки — в 1–2 ряда по ширине экрана, в альбомной
  ориентации показатели и кнопки справа. Клавиши: 1–9, 0 — пробирки 1–10; стрелки + Enter / пробел; Esc — снять
  выбор / пауза; U / Backspace / Ctrl+Z — отмена; H — подсказка; T — пробирка; R — заново; N — новая (свободная игра);
  P — пауза. Настройки: значки на цветах, авто-перелив, номера пробирок, анимация (обычная / быстрая / выкл.), звук,
  вибрация.
- **Очки:** на платформу не отправляются (`submitScore` не вызывается — как и в прежней версии).
- **Хранилище** (`localStorage`): `watersort2` (прогресс кампании: звёзды, лучшие ходы и время по уровням),
  `watersort2_stats`, `watersort2_ach`, `watersort2_daily`, `watersort2_settings`, `watersort2_save` (незаконченные
  партии). При первом запуске прогресс прежней версии (`watersort_completed`, `watersort_best`, 12 уровней)
  переносится на уровни 1–12 со звёздами по прежним правилам; прежние ключи не удаляются.

### 🎱 Русский бильярд

| | |
|---|---|
| **Файл** | `apps/billiard.html` |
| **Категория** | 🕹️ Аркады |
| **Описание** | Русская пирамида до 8 очков — свободная или московская (комбинированная), вдвоём на одном устройстве или по сети |

Стол 12 футов (поле 3550 × 1775 мм), 16 шаров ⌀ 68 мм (15 белых с номерами и жёлтый), лузы по стандарту: угловые 73 мм, средние 83 мм. Правила — по общим правилам пирамиды Международной конфедерации пирамиды и Лиги любителей бильярда (разделы «Свободная пирамида» и «Комбинированная пирамида»). Вид пирамиды выбирается в меню перед партией.

- **Разбой** — только жёлтым битком «с руки» из дома: биток ставится в любую точку между линией дома и коротким бортом, но не на линию (положение — по центру шара, шар на линии — вне дома). В следующей партии разбивает соперник.
- **Правильный разбой:** после соударения битка с прицельным шаром забит любой шар, или бортов коснулись 3 разных прицельных шара, или 2 — и хотя бы один прицельный пересёк среднюю линию. Иначе — фол; соперник снимает штрафной шар и выбирает: принять позицию и бить самому / передать удар, или перестановка пирамиды (неполной — ряды сверху вниз, последний симметрично от середины) и разбой самому / нарушителю.
- **Правильно завершённый удар** (п. 20, кроме разбоя): после соударения забит шар или шары «отыграли» — шар после борта коснулся другого борта (шара у другого борта, довёл до другого борта шар), или пересёк среднюю линию и затем коснулся борта (…), или после борта пересёк среднюю линию (перекатил через неё шар, коснулся шара за ней). Отскок от носа губки средней лузы считается пересечением средней линии. Иначе — фол.
- **Фол и штрафной шар:** биток никого не задел, удар завершён неправильно, неправильный разбой, нарушение удара с руки (московская). Забитые при фоле шары ставятся на заднюю отметку (несколько — по линии к заднему борту вплотную; мешают шары — как можно ближе к отметке, не вплотную; нет места — к центру стола). Затем соперник снимает со стола любой шар себе на полку — штрафной (+1 очко; на полке с красным кольцом) — и решает: бить самому или передать удар нарушителю.
- **Свободная пирамида:** битком может быть любой шар (кроме разбоя); каждый забитый шар — очко, в том числе биток после удара по другому шару («свояк»); штрафным можно снять любой шар, даже жёлтый (тогда после неправильного разбоя перестановка недоступна).
- **Московская (комбинированная) пирамида:** биток — только жёлтый. Правильный свояк: забивший снимает любой прицельный шар себе на полку (+1, зелёное кольцо) и бьёт с руки из дома. Удар с руки: биток — в доме, не на линии и не вплотную к шарам; фол, если биток до выхода из дома задел шар в доме, не коснулся ни одного шара вне дома или шар упал в лузу раньше этого касания. Если все прицельные шары в доме — удар из «временного дома» за задней линией. Штрафной шар — только прицельный; если при фоле биток упал в лузу, после штрафного шара его ставит с руки тот, кто будет бить. Шары вне дома (по ним можно бить первыми) подсвечены зелёным, в доме — красным.
- **Судья** — по событиям той же физики: касания бортов (номер борта; губки — часть своего борта), «шар у борта» (зазор ≤ 1 мм), пересечения средней линии по центру шара, кто кого толкнул (по скоростям вдоль линии центров), лузы, выход битка из дома. Решение детерминировано: у соперника по сети при повторе удара получается тот же итог (сверяется).
- **Биток с руки (2D и 3D):** дом подсвечен, биток — бегущим пунктиром. Тяните шар пальцем или мышью, тапните в доме — он встанет туда; туда, где нельзя (за линией и на линии дома, вплотную к шару, у лузы, в борт), шар не встаёт — встаёт в ближайшую допустимую точку, красный «призрак» показывает, куда тянули, и всплывает подсказка. Прицел держится на цели, пока двигаете шар, траектория пересчитывается. «Готово» (Enter / пробел) — к прицелу, «✋ Переставить» (H) — снова двигать; тап или ведение вне дома — сразу прицел. Стрелки — сдвиг на 2 мм (Shift — 2 см) по направлениям экрана. В 3D камера встаёт над домом и не двигается, протяжка по столу двигает шар (точка на плоскости стола); после «Готово» — камера за битком.
- **Выбор шара на полку** (штрафной / за свояк): шары подсвечены жёлтым — тап по шару и «Снять» (или второй тап по нему); клавиши — стрелки и Enter. Затем окно выбора: бить самому / передать удар (после неправильного разбоя — и перестановка).
- **Физика** — шар как твёрдое тело (скорость и вектор вращения), фиксированный шаг 1/1200 с:
  - сукно: скольжение (μ = 0,2), пока вращение не «догонит» шар, затем сопротивление качению (μ = 0,011); вращение вокруг вертикали гаснет отдельно — отсюда накат, оттяжка и стоп-удар;
  - шар–шар: восстановление 0,95 и трение в точке контакта (μ = 0,06) — отброс прицельного на 1–3° при резке и при винте; момент касания уточняется внутри шага;
  - борт: нос резины выше центра шара (64 % диаметра), упругость падает с силой удара, трение о резину меняет угол отскока при боковом винте;
  - лузы: губки скруглены, стенки расходятся вглубь; шар падает, когда его центр ушёл за кромку плиты сразу за створом; задевший губку может «задребезжать» и выскочить.
- **Наклон кия** 0–75° (удар сверху): удар раскладывается на скорость вдоль стола (× cos угла) и вращение вокруг оси, перпендикулярной кию, — с боковым винтом шар идёт по дуге (массе), с оттяжкой быстрее гасит ход.
- **Прицел** считается той же физикой: учитывает отброс, скорость (крестик — шар не докатится) и дребезг в губках; пунктир — путь битка после удара (накат, оттяжка и массе изгибают его).
- **Полная траектория** — весь удар просчитывается заранее на копии стола тем же шагом физики, что и сам удар (совпадение бит-в-бит): пути всех сдвинутых шаров до остановки, отскоки, лузы. Глубина 1–5 или «Все» — сколько шаров по цепочке показывать (биток → шары, которые он ударит → …). Считается кусками не больше ~6 мс за кадр, поэтому прицел не подтормаживает; пока новый прогноз не готов, виден прежний (бледнее).
- **3D-вид** (WebGL 1, без библиотек): тот же стол — сукно, метки и лузы как текстура из 2D-слоя, объёмные борта и резина, царга, ножки, паркет со светом ламп; шары-сферы с освещением трёх ламп, номерами и мягкими тенями, кий с наклоном. Камера за битком по линии прицела, при установке битка — над домом, «Обзор» — весь стол; пока шары катятся и при выборе шара на полку — обзор автоматически. Протяжка по столу — прицел и высота камеры, щипок/колесо — приближение, тап по шару — выбрать биток (или шар на полку), по сукну — прицел. Потеря контекста WebGL переживается (всё создаётся заново). Без WebGL — сообщение и 2D.
- **Графика:** стол рисуется один раз в буфер — брус «на ус» с текстурой дерева, перламутровые метки, кожаные лузы с латунью и сеткой, сукно с фактурой и светом трёх ламп. Шары — попиксельное освещение, блики и мягкие тени от каждой лампы; номера катятся вместе с шаром (ориентация — кватернион). Кий с наклейкой, кольцом и обмоткой: отходит назад при натяжении силы, бьёт и проводит удар.
- **По сети** (KuNet, идентификатор игры `billiard2`, протокол 3): вид пирамиды задаёт создатель комнаты (в `meta` комнаты — его видно в списке комнат, гостю — подсказка при входе). Каждое действие того, чей ход, — отдельный ход KuNet: удар (стартовая расстановка с полной точностью, скорость и вращение битка, условия удара для судьи), снятый шар, выбор после фола; ход сервера передаётся тому, кто действует следующим. Соперник проигрывает удар у себя (та же физика и тот же судья), затем ставит всё по снимку; пропущенный между опросами удар проигрывается по номеру, решения соперника показываются подсказками («снял штрафной шар 7», «передал удар»). Пока соперник выбирает — «Соперник выбирает…». Ходы отправляются по очереди, при сбое сети — повтор. Старая версия игры из кэша не смешивается с новой: у новой свой идентификатор (комнаты не видны друг другу в списках), а при входе по коду в комнату другой версии или при первом ходе старого клиента новая версия показывает «РАЗНЫЕ ВЕРСИИ» и выходит из комнаты (у старого — «Соперник вышел»). Реванш — разбивает соперник. Вид 2D/3D у каждого свой.
- **Управление:** тап по шару — выбрать биток (свободная); тап или ведение по столу — прицел; микро-прицел (медленно — доли миллиметра); винт — протяжка по маленькому шару или окно точной настройки по тапу (шаг 1 %, проценты наката/оттяжки и бокового, наклон кия); сила в процентах с шагом 1 % (шкала, − / +). Режим «Бить кнопкой «Ударить»» (по умолчанию): силу выставил — она стоит, поправил прицел — «Ударить»; выключен — удар при отпускании шкалы (тап без протяжки не бьёт). Клавиши ← → (Shift — крупнее), ↑ ↓ — сила ±1 % (Shift — 5 %), пробел / Enter — удар; при установке битка — стрелки двигают шар, Enter — «Готово», H — переставить; P / Esc — пауза.
- **Настройки** (окно «Настройки» и меню партии): сукно, режим удара, траектория (обычная / полная + глубина), вид 2D / 3D, номера на шарах; вид пирамиды — в меню. Всё сохраняется в `localStorage`.
- **На телефоне** (короткая сторона экрана ≤ 560 px) стол занимает почти весь экран (~80 % в портрете): сверху — счёт одной строкой и кнопка ☰, снизу только управление (винт, точный прицел, сила — горизонтальная шкала, тянуть вправо); в альбомной ориентации сила — слева, остальное — справа. Подсказка над столом («биток с руки · Готово», «выберите шар · Снять») уходит вниз, если закрывает шары на выбор или временный дом. Панели игроков с полками шаров, сукно, настройки, правила и действия (продолжить, заново, в меню) — в меню партии ☰. Чей ход — видно по строке счёта и цвету свечения рамки стола. На планшете и компьютере — прежняя раскладка.
- **Очки:** на платформу не отправляются (`submitScore` не вызывается — как и в прежней версии).
- **Хранилище** (`localStorage`): `billiard_prefs` — `{ v: 2, theme, numbers, traj, depth, shootBtn, view3d, kind }` (`kind`: `free` | `moscow` — вид пирамиды в меню; прежние настройки читаются как раньше, испорченные значения игнорируются).

### 🟡 Pac-Man

| | |
|---|---|
| **Файл** | `apps/pacman.html` |
| **Категория** | 🕹️ Аркады |
| **Описание** | Pac-Man по правилам аркады Namco (1980): 4 привидения с характерами, фрукты, «Круиз Элрой», таблицы скоростей и испуга по уровням, плюс 3 своих лабиринта |

Съешьте все точки лабиринта — откроется следующий уровень; с каждым уровнем всё быстрее, а испуг короче. Таблицы
и правила взяты из «The Pac-Man Dossier» (J. Pittman) — разбор кода оригинального автомата.

- **Режимы:** 🎮 **Классика** — лабиринт аркады (240 точек + 4 энерджайзера), уровни без конца. 🌀 **Лабиринты** —
  три своих лабиринта (не копии Ms. Pac-Man): «Сетка», «Лесенка» и «Сквозняк» (два туннеля у углов), каждый на
  2 уровня по кругу; правила те же, рекорды раздельные. Все лабиринты проверены тестом: связны, без тупиков и
  площадок 2×2, туннели сквозные.
- **Привидения** (характеры аркады): Блинки целится в клетку Pac-Man; Пинки — на 4 клетки перед ним; Инки — в точку,
  симметричную Блинки относительно клетки в 2 шагах перед Pac-Man; Клайд гонится, пока дальше 8 клеток, ближе —
  уходит в свой угол. Когда Pac-Man смотрит вверх, цели Пинки и Инки смещаются ещё и влево (как в оригинале).
  Направление выбирается в центре клетки — ближе к цели по прямой, без разворота; при равенстве — вверх, влево,
  вниз, вправо. Испуганные выбирают случайно. Цели разбега — за пределами лабиринта у «своих» углов.
- **Разбег / охота:** 7/20/7/20/5/20/5 с, дальше охота (1 уровень); 7/20/7/20/5/1033 с/1 кадр (2–4);
  5/20/5/20/5/1037 с/1 кадр (5+). Таймер стоит во время испуга. При смене режима и при энерджайзере вышедшие
  привидения разворачиваются (при выходе из испуга — нет); получившее сигнал в домике выйдет вправо, а не влево.
  «Красные зоны»: в 4 клетках над домиком и над стартом Pac-Man в разбеге и охоте нельзя повернуть вверх.
- **Домик:** Блинки снаружи; Пинки выходит сразу, Инки — после 30 точек, Клайд — ещё после 60 (2 уровень:
  0/0/50, с 3-го — сразу); точки считает только первое в очереди привидение. После потери жизни — общий счётчик:
  Пинки на 7-й точке, Инки на 17-й, на 32-й (если Клайд дома) снова работают личные. Если 4 с (с 5 уровня — 3 с)
  не есть точки, выходит очередное привидение. Глаза съеденного летят к двери, ожившее сразу выходит.
- **Скорости** (100 % = 75,76 пикс/с аркады): Pac-Man 80 % → 90 % (2–4) → 100 % (5–20) → 90 % (21+), на 1–4
  уровнях в испуге быстрее; на каждой точке он стоит 1 кадр, на энерджайзере — 3, поэтому по пустым коридорам
  быстрее (~71 % → 80 % на 1 уровне). Привидения 75/85/95 %, в туннеле 40/45/50 %, испуганные 50/55/60 %, глаза —
  вдвое быстрее максимума. Pac-Man «срезает» углы, привидения — нет.
- **«Круиз Элрой»:** при 20 и 10 оставшихся точках на 1 уровне (дальше 30/15 … 120/60) Блинки ускоряется до
  80/85 % … 100/105 % и в разбеге продолжает охоту; после гибели Pac-Man — без ускорения, пока Клайд не выйдет.
- **Испуг:** 6, 5, 4, 3, 2, 5, 2, 2, 1, 5, 2, 1, 1, 3, 1, 1 с на уровнях 1–16, на 17-м нет, на 18-м — 1 с,
  с 19-го нет — привидения только разворачиваются; в конце 5 миганий (на коротком испуге — 3).
- **Фрукты:** после 70-й и 170-й точки под домиком на 9–10 с: вишня 100, клубника 300, апельсин 500 (3–4),
  яблоко 700 (5–6), дыня 1000 (7–8), «Галаксиан» 2000 (9–10), колокол 3000 (11–12), ключ 5000 (13+). Внизу поля,
  как в аркаде: слева запасные жизни, справа фрукты последних 7 уровней.
- **Очки:** точка 10, энерджайзер 50, привидения 200 → 400 → 800 → 1600 подряд за один энерджайзер (после каждого —
  пауза 1 с с очками на месте привидения), фрукты 100–5000; одна дополнительная жизнь за 10 000. Всех 16 привидений
  за уровень — достижение «Гроза привидений» (без бонус-очков: в аркаде его нет).
- **Статистика** по режимам и всего (партии, рекорд, лучший и пройденные уровни, средний счёт, точки, привидения,
  серии 1600, фрукты, потерянные и доп. жизни, время), **история** 30 партий (прерванные отмечены),
  **15 достижений**.
- **Игра:** фиксированный шаг логики 60 тиков/с (одинаково на 30/60/120/144 Гц), «ГОТОВЬСЯ!» перед стартом и после
  гибели, пауза при скрытии вкладки, звуки (WebAudio) и вибрация. Партия, брошенная через «В меню» или закрытием
  страницы, засчитывается как прерванная.
- **Управление:** стрелки / WASD (и ЦФЫВ), свайпы по полю, экранная крестовина (настройка: авто / всегда / скрыть;
  на компьютере с мышью «авто» её прячет), поворот можно нажать заранее — Pac-Man свернёт в первом же проходе.
  P / Esc — пауза, M — звук. В альбомной ориентации показатели слева, крестовина справа от поля.
- **Очки на платформу** игра не отправляет (и прежняя версия не отправляла).
- **Хранилище** (`localStorage`): `pacman_stats` (рекорды и статистика по режимам; рекорд, число игр и лучший
  уровень прежней версии переносятся в «Классику», поля `best`/`games`/`maxLevel` сохраняются для совместимости),
  `pacman_settings`, `pacman_ach`, `pacman_history`. Испорченные данные не ломают игру.

## 6. PWA и офлайн-режим

- **Установка:** на Android/iOS нажмите «Добавить на главный экран» в браузере
- **Версия кэша:** `app-v18`

**Стратегия кэширования (Service Worker):**

| Тип | Стратегия | Файлы |
|---|---|---|
| Оболочка | Cache First (предзагрузка при установке) | `index.html`, `manifest.json`, иконки |
| Приложения | Cache First (кэшируются при первом открытии) | `apps/*` (игры, `ku-arcade.*`, шрифты), `workouts/*.json` |
| Внешние API | Bypass (не кэшируются) | Google Sheets API, OAuth, CDN |

> После любых изменений в `apps/` поднимайте `CACHE_NAME` в `sw.js` — иначе установленное PWA продолжит
> показывать старые версии игр из кэша.

**Команды SW (через postMessage):**
- `CLEAR_CACHE` — очистить все кэши
- `GET_CACHE_INFO` — информация о кэше
- `SKIP_WAITING` — активировать обновление

### Оформление игр — единый стиль `ku-arcade`

Все игры оформлены в одном стиле «Неоновая аркада», эталон — Тетрис: тёмно-синий градиент с неоновыми пятнами
и сеткой, стеклянные панели и кнопки, заголовки шрифтом Russo One, текст — Rubik, акценты `#00e5ff` / `#ff4dd2`,
палитра фигур Тетриса как общая палитра. Стиль лежит в `apps/ku-arcade.css` + `apps/ku-arcade.js`, классы с префиксом
`ku-`, переменные совпадают с Тетрисом (`--bg1`, `--accent`, …).

```html
<link rel="stylesheet" href="ku-arcade.css">
<script src="ku-arcade.js"></script>
<body class="ku">
<main class="ku-app">

    <h1 class="ku-logo">МОЯ ИГРА</h1>                       <!-- буквы раскрасятся автоматически -->

    <div class="ku-menu-btns">
      <button class="ku-btn big primary">🎮 Играть<span class="best">Рекорд: 0</span></button>
    </div>
    <div class="ku-menu-row"><button class="ku-btn ghost">📖 Правила</button></div>
  </section>
  <section id="screen-game" class="ku-screen fit">
    <header class="ku-top">
      <div class="ku-top-left"></div>                        <!-- здесь кнопка «←» платформы -->

    </header>
    <div class="ku-hud"><div class="ku-stat"><span>Очки</span><b>0</b></div></div>
```

Правила:
- Внутри платформы левый верхний угол (~64×64 px) закрыт кнопкой «←» платформы — `ku-arcade.js` ставит
